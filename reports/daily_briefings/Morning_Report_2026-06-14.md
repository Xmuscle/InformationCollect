### 1. [EvoArena: Tracking Memory Evolution for Robust LLM Agents in Dynamic Environments](https://arxiv.org/abs/2606.13681)
> ⚡ EvoArena团队推出了一个动态环境基准测试套件EvoArena，并配套提出基于补丁的记忆范式EvoMem，专门评估LLM agent在终端、软件和社交等持续变化场景中的适应能力。当前主流agent在该基准上的平均准确率仅39.6%，而EvoMem不仅带来1.5%的提升，还能在GAIA和LoCoMo等标准测试中分别提高6.1%和4.8%——这说明记忆的动态演化机制对agent的可靠部署至关重要。
👤 Jundong Xu, Qingchuan Li | 📅 2026-06-11

**详情:** 大语言模型（LLM）智能体在众多基准测试中取得了优异表现，但大多数评估仍假设环境是静态的。相比之下，现实世界的部署本质上是动态的，要求智能体持续将其知识、技能和行为与不断变化的环境及更新的任务条件对齐。为弥补这一差距，我们提出EvoArena基准套件，该套件将环境变化建模为终端、软件和社交领域中的渐进式更新序列。我们进一步提出EvoMem，一种基于补丁的记忆范式，将记忆演化记录为结构化的更新历史，使智能体能够通过记忆中的变化来推理环境演化。实验表明，当前智能体在EvoArena上表现不佳，在演化的终端、软件和社交偏好领域平均准确率仅为39.6%。EvoMem持续提升性能，在EvoArena上平均提升1.5%，同时在GAIA和LoCoMo等标准基准测试上分别提升6.1%和4.8%。除单个任务外，EvoMem在EvoArena上还将链级准确率提升了3.7%，该任务要求成功完成一系列连续相关的演化子任务。机制分析表明，EvoMem改善了记忆中的证据捕获，表明其能更完整地保留演化中的环境状态。我们的结果强调了在评估和记忆中对演化进行建模对于智能体可靠部署的重要性。

### 2. [MiniMax Sparse Attention](https://arxiv.org/abs/2606.13392)
> ⚡ MiniMax团队提出了MiniMax Sparse Attention（MSA），一种基于Grouped Query Attention（GQA）的块级稀疏注意力机制，通过轻量级Index Branch为每个GQA组独立选择Top-k KV块，再在Main Branch执行精确的块稀疏注意力。在109B参数的多模态模型上，MSA在1M上下文长度下将单token注意力计算量降低28.4倍，配合自研GPU内核在H800上实现14.2倍prefill和7.6倍decoding加速，让超长上下文LLM的部署变得切实可行。
👤 Xunhao Lai, Weiqi Xu | 📅 2026-06-11

**详情:** 超长上下文能力正成为前沿大语言模型不可或缺的能力：智能体工作流、仓库级代码推理以及持久记忆均要求模型能够共同关注数十万至数百万个词元，然而软注意力机制的二次方计算代价使得这一需求在部署规模下难以实现。我们提出MiniMax稀疏注意力机制（MSA），这是一种基于分组查询注意力（GQA）构建的分块稀疏注意力机制。一个轻量级的索引分支对键值块进行评分，并为每个GQA分组独立选择Top-k子集，从而在保持高效块级执行的同时实现分组特定的稀疏检索；主分支则仅对所选块执行精确的块稀疏注意力。基于简洁性与可扩展性原则设计，MSA经过刻意精简，使其能够轻松地在各类GPU上高效部署。为将稀疏性转化为实际加速效果，我们与MSA协同设计了GPU执行路径，该路径采用无指数Top-k选择与KV外稀疏注意力，以提升块粒度访问下的张量核心利用率。在具有原生多模态训练的109B参数模型上，MSA在性能与GQA相当的同时，在1M上下文长度下将每个词元的注意力计算量减少了28.4倍。结合我们协同设计的内核，MSA在H800上实现了14.2倍的预填充加速和7.6倍的解码端到端加速。我们的推理内核已开源至：https://github.com/MiniMax-AI/MSA。由MSA驱动的生产级原生多模态模型已公开发布于：https://huggingface.co/MiniMaxAI/MiniMax-M3。

### 3. [WeaveBench: A Long-Horizon, Real-World Benchmark for Computer-Use Agents with Hybrid Interfaces](https://arxiv.org/abs/2606.09426)
> ⚡ WeaveBench团队推出了一款长周期混合界面基准测试，包含114个真实工作域任务，要求智能体在同一轨迹中融合GUI操作与CLI/代码执行。目前最强模型-运行时组合的通过率仅41.2%，说明跨界面编排能力远未饱和，且轨迹感知裁判发现仅以结果评分会严重高估智能体表现。
👤 Wanli Li, Bowen Zhou | 📅 2026-06-08

**详情:** 计算机使用代理（CUA）日益在融合可视化桌面控制、命令行执行、代码编辑、浏览器及外部工具的运行环境中运行。然而，现有基准测试往往将这些接口作为独立能力进行评估，导致对长周期跨接口协同能力的测试不足。为此，我们提出WeaveBench——一个长周期混合接口基准测试，涵盖8个真实工作领域的114项任务，所有任务均基于真实用户请求与可公开验证的工件。每项任务要求代理在单次运行轨迹中结合图形用户界面（GUI）观察/操作与命令行界面（CLI）/代码操作。我们在已部署的CLI代理运行环境中的真实Ubuntu桌面上对这些任务进行评估，并辅以最小化桌面控制插件。我们还提出了一种配套的轨迹感知评估器，用于检查交付物、文件、截图、日志及操作痕迹，同时检测诸如伪造视觉证据或硬编码指标等捷径行为。在主流模型-运行环境组合中，最佳通过率仅为41.2%，表明该基准测试远未达到饱和状态。轨迹感知评估器进一步揭示，仅基于结果的评分会显著高估代理性能。总体而言，WeaveBench揭示了CUA评估中的关键缺口，并为衡量代理能否在长周期真实世界任务中协调GUI、CLI与代码操作提供了有效测试平台。

### 4. [SpatialClaw: Rethinking Action Interface for Agentic Spatial Reasoning](https://arxiv.org/abs/2606.13673)
> ⚡ 我们团队提出了 SpatialClaw，一个无需训练的框架，通过将代码作为 action interface，让 VLM 驱动的 agent 能逐步编写并执行 Python 代码，灵活组合 perception 模块处理 3D/4D 空间推理。在 20 个空间推理 benchmark 上，它平均准确率达 59.9%，比现有空间 agent 高出 11.2 个百分点，且在不同 VLM 上表现一致——这意味着用代码接口替代固定 tool-call 或单次执行，能显著释放模型处理复杂空间关系的潜力。
👤 Seokju Cho, Ryo Hachiuma | 📅 2026-06-11

**详情:** 空间推理——即确定物体位置、相互关系及三维运动的能力——仍是视觉语言模型（VLM）面临的根本性挑战。工具增强型智能体试图通过为VLM配备专业感知模块来解决这一问题，但其有效性受限于调用这些工具所依赖的动作接口。本研究探讨了该接口的设计如何塑造智能体在开放式空间推理中的能力。现有空间智能体要么采用单次代码执行策略（在观察到任何中间结果之前即确定完整分析方案），要么依赖结构化工具调用接口（该接口在自由组合操作或针对特定任务定制分析方面灵活性不足）。这两种设计均难以满足开放式、复杂三维/四维空间推理的需求。为此，我们提出SpatialClaw——一种无需训练的空间推理框架，采用代码作为动作接口。SpatialClaw维护一个带状态管理的Python内核，预加载输入帧及一系列感知与几何基元，使基于VLM的智能体能够基于所有先前输出逐步编写可执行单元，从而灵活组合与操控感知结果，并根据中间文本/视觉观测及具体问题需求动态调整分析策略。在涵盖广泛静态与动态三维/四维空间推理任务的20个空间推理基准测试中，SpatialClaw实现了59.9%的平均准确率，较最新空间智能体提升11.2个百分点，并在来自两个模型家族的六种VLM骨干网络上取得一致性增益，且无需针对特定基准或模型进行适配。

### 5. [Robust-U1: Can MLLMs Self-Recover Corrupted Visual Content for Robust Understanding?](https://arxiv.org/abs/2606.08063)
> ⚡ Robust-U1团队提出一个让多模态大模型（MLLMs）自己修复受损视觉内容的新框架，通过监督微调、强化学习（结合SSIM和CLIP双重奖励）以及多模态推理三步走。有意思的是，他们发现高质量的视觉自恢复能直接提升推理表现，在真实世界和对抗性视觉损坏测试中都达到了SOTA——这相当于给MLLMs装了个“自愈”能力，比之前黑盒对齐或纯文本推理靠谱多了。
👤 Jiaqi Tang, Jianmin Chen | 📅 2026-06-06

**详情:** 多模态大语言模型（MLLMs）在视觉理解领域已展现出显著成功，但在真实世界视觉退化条件下其性能会大幅下降。现有鲁棒性增强方法存在局限性：黑盒特征对齐缺乏可解释性，而白盒基于文本的推理无法恢复丢失的像素级细节。本研究探讨一个基础性研究问题：多模态大语言模型能否自主恢复受损的视觉内容？为此，我们提出Robust-U1——一种赋予多模态大语言模型显式视觉自恢复能力以实现鲁棒理解的新型框架。该方法包含三个核心阶段：用于初始重建的监督微调、结合双重奖励（像素级SSIM与语义级CLIP相似度）的强化学习以对齐高视觉质量，以及联合考虑退化输入与恢复图像的多模态推理。大量实验表明，Robust-U1在真实世界退化基准测试中实现了最先进的鲁棒性，并在通用VQA基准测试的对抗性退化条件下保持优越性能。分析证实，高质量视觉恢复直接提升了推理性能，从而确立自恢复机制作为鲁棒视觉理解的关键机制。源代码已开源至https://github.com/jqtangust/Robust-U1。
