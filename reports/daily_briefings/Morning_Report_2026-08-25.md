### 1. [EnvHarness: Awakening Static Worlds for Agent Learning](https://arxiv.org/abs/2608.19880)
> ⚡ EnvHarness团队提出了一套可编程的插件层，通过标准接口包装静态环境来动态重塑其行为，无需改动底层逻辑，并配套EnvRigger自动诊断策略缺陷并合成组件。这套方案在四个领域的五个基准上平均提升9.0分，还减少了9.8%的执行步骤，关键是为强化学习提供了更优的优化信号，让策略与环境能持续协同进化，省去了重复造环境的工程负担。
👤 Chengsong Huang, Zifeng Wang | 📅 2026-08-20

**详情:** LLM智能体通过与环境的互动进行学习，然而这些环境均为手工构建且静态不变：它们对智能体的弱点视而不见，并随着智能体的进步迅速变得不再具有挑战性。尽管近期环境生成方法试图解决这一问题，但它们依赖于特定领域的流程，依赖昂贵或不可靠的验证器，且仍然生成静态环境。为减轻从零开始重建环境的工程负担，我们提出环境操控框架（EnvHarness），这是一个可编程的即插即用组件层，能够在不修改底层逻辑的前提下，对静态环境进行包装以重塑其行为。EnvHarness通过标准接口运作，适用于多种领域，同时确保每个重塑后的环境保留其原有的验证器。为使这一过程自动化，我们引入EnvRigger，它将目标策略视为黑盒，通过观察其执行轨迹来综合生成针对所诊断缺陷的EnvHarness组件，并通过全新的随机 rollout 进行验证。在四个领域的五个基准测试中，EnvHarness在保留实例上的表现优于原始环境和特定领域的环境生成流程，最高提升达9.0分，同时执行步骤减少9.8%。此外，EnvHarness为强化学习提供了更优的优化信号，使策略与其环境能够持续、有针对性地协同进化。

### 2. [FACET: Preserving Source Intent and Executable State in Terminal Task Synthesis](https://arxiv.org/abs/2608.18580)
> ⚡ FACET框架通过细粒度智能体构建，将相关agent技能重构为信息丰富的终端任务场景，并在生成指令、参考解和验证器前先修复执行环境，确保各组件共享同一容器状态。这一方法解决了多阶段合成中目标依赖丢失和跨工件不一致的难题，其产生的密集可执行检查任务在Terminal-Bench 2.1上显著提升了多规模模型的微调性能，为可扩展终端任务合成确立了环境接地与源意图保留两大核心原则。
👤 Kou Shi, Zun Wang | 📅 2026-08-19

**详情:** 训练终端代理需要可扩展的可执行监督，然而合成高质量的终端任务仍然具有挑战性。每个任务都包含一条指令、一个初始化环境、一个参考解决方案和一个可执行验证器；如果这些构件是从不一致的假设中生成的，所产生的任务可能无法求解或被错误评估。与此同时，多阶段合成可能会丢弃原始来源中编码的目标、依赖关系、状态转换和过程约束。我们提出了FACET（可执行任务的细粒度智能体构建），这是一个同时解决信息保留和跨构件一致性的框架。FACET将相关的智能体技能重构为连贯、信息丰富的场景，然后在生成最终任务构件之前实现并修复执行环境。由此产生的容器状态为指令、解决方案和验证器提供共享基础，而基于执行的验证和针对性修复则纠正特定于构件的失败，而无需不必要地重新生成有效组件。FACET生成具有密集可执行检查的复杂终端任务，从这些任务中收集的成功轨迹提供了有效且数据高效的监督。在多个规模上对模型进行微调持续提升了Terminal-Bench 2.1上的性能，而对替代生成方案的分析则支持了环境接地构建对任务有效性和解决方案-验证器一致性的重要性。这些结果确立了源意图保留和共享可执行状态接地作为可扩展终端任务合成的关键原则。

### 3. [4DAnyone: Create Anyone in 4D from a Casual Monocular Video](https://arxiv.org/abs/2608.20335)
> ⚡ 4DAnyone框架能从单目视频重建4D人体，通过生成多视角一致的视频并提升为4D Gaussian Splatting（4DGS），解决了现有扩散模型在目标视角过多时因注意力上下文受限导致的视角不一致问题。其核心创新是Reference Context Packing（RCP）和Target Context Routing（TCR），前者将参考视角压缩为固定长度混合分辨率上下文，后者在去噪过程中轮转目标视角分组以平衡全局结构与细节稳定，实验表明在DNA-Rendering和DyMVHumans上显著优于此前方法，且具备野外泛化能力。
👤 Yudong Jin, Tao Xie | 📅 2026-08-20

**详情:** 我们提出了4DAnyone，这是一个从未标定的单目视频中重建4D人体的框架，其方法是通过生成重建级的多视角一致视频，并将其提升为4D高斯泼溅（4DGS）。现有的相机控制视频扩散模型能够合成看似合理的新视角视频，但当扩展到4DGS重建所需的数十个目标视角时，这些模型无法保持一致性。我们将这一失败归因于受限的注意力上下文问题：当目标视角超过单次DiT前向传播的容量时，必须将其拆分为多个组，从而暴露出两个相互耦合的瓶颈。在参考上下文方面，对所有先前生成视角的条件依赖以O(N)的速度增长，削弱了跨视角的外观引导。在目标上下文方面，不相连的组无法直接交换信息，导致全局结构漂移。4DAnyone通过两种互补设计解决了这两个瓶颈：参考上下文打包（RCP）将不断增长的参考视角压缩为固定长度的混合分辨率上下文，实现O(1)的参考上下文复杂度；目标上下文路由（TCR）在去噪过程中轮换目标视角的分组，从而在高噪声步骤中跨组共享上下文，并在低噪声步骤中稳定细节。我们进一步利用自有的游戏引擎构建了MVGameHuman数据集，并将其与光舞台和野外视频数据集结合用于训练。在DNA-Rendering和DyMVHumans上的实验表明，4DAnyone在新视角视频质量和下游4DGS重建方面均优于先前方法，并展现出稳健的野外泛化能力。视频结果和源代码请参见我们的项目页面：https://4danyone.github.io。

### 4. [SWE-bench Science: Can Coding Agents Resolve Engineering Tasks in Science?](https://arxiv.org/abs/2608.19799)
> ⚡ 我们推出了SWE-bench Science，一个覆盖20个科学领域、98个仓库、119个任务的科学软件工程基准，连最强的Claude Code（Opus-5）通过率都不到50%。分析发现，智能体失败主要卡在科学知识欠缺、探索方向跑偏、修复不彻底和泛化不足这四类问题上。有意思的是，消融实验显示科学知识并非越多越好——贴合的指导能提升效率和修复质量，但误导性信息反而会引发锚定效应，这提醒我们在给coding agent注入领域知识时得讲究“精准投喂”。
👤 Zhipeng Xu, Jiahao Lu | 📅 2026-08-20

**详情:** 软件日益成为科学仪器本身的组成部分，这使得科学代码中的故障不仅可能损害程序行为，还可能损害支撑科学结论的证据。然而，现有对编码智能体的评估大多侧重于整体任务成功率，对于智能体在修复科学软件时为何失败所提供的洞察十分有限。我们引入了SWE-bench Science，一个面向科学软件工程的仓库级基准测试，包含来自20个科学领域、98个GitHub仓库的119个任务。每个任务被归入三种范式之一：问题驱动型、专家探索型和工程集成型。即使性能最佳的智能体Claude Code with Opus-5（max），其pass@1也低于50%，凸显了科学软件工程所带来的巨大挑战。我们识别出四种反复出现的失败机制：科学知识或抽象能力的欠缺、误导性探索或表面化修复、修复覆盖不完整或系统集成不足，以及未能将科学知识推广到分析中观察到的案例之外。我们进一步进行了配对消融实验，在保留仓库和可执行工程上下文的同时移除明确的科学指导。结果表明，科学知识并非总是有益的：有充分依据的信息可以约束修复过程并提高平均性能和令牌效率，而契合度较差的指导则可能引发锚定效应，且不一定能提高精确修复的成功率。综上所述，SWE-bench Science为研究编码智能体在科学软件工程中的能力与失败机制提供了一个广泛的测试平台。

### 5. [WithEveryone: Unified Planning and Identity Grounding for Group Image Generation](https://arxiv.org/abs/2608.20336)
> ⚡ WithEveryone框架实现了单次生成最多十人合影的突破，通过为每个身份注入寻址token并生成结构化布局计划，配合Layout-Grounded ID Loss直接监督面部区域，解决了多身份绑定难题。在身份不重叠的基准测试中，其目标人脸相似度从GPT-Image-2的0.462提升至0.499，复制粘贴伪影从0.169降至0.055，身份覆盖率达97.3%且重复率仅2.8%，证明显式身份-布局对齐能让群像生成摆脱直接参考人脸复制的局限。
👤 Hengyuan Xu, Qixun Wang | 📅 2026-08-20

**详情:** 当场景中必须包含多个指定人物时，保持身份一致性的图像生成变得愈发不可靠。除了保留每个身份特征外，模型还必须将每个参考图像绑定到不同的人物和位置，而训练时的身份损失函数则需要在多个含噪的预测人脸之间建立对应关系。我们提出WithEveryone，一个统一的框架，用于生成包含多达十个参考身份的群像图像。WithEveryone将每个选定的身份注入为带地址的令牌，预测结构化的身份-布局方案，并将该方案渲染为视觉条件。其关键目标——布局引导身份损失（Layout-Grounded ID Loss），利用标注的人脸区域直接监督目标身份，避免了不稳定的基于嵌入的人脸匹配；身份表示强制（ID Representation Forcing）则在图像合成之前额外对每个身份进行预测训练。在身份不重叠的基准测试上，WithEveryone取得了最高的目标上下文身份相似度，将人脸相似度从GPT-Image-2的0.462提升至0.499，同时将复制粘贴伪影从0.169降至0.055。此外，它覆盖了97.3%的请求身份，重复率仅为2.8%。这些结果表明，显式的身份-布局锚定能够使身份保持生成扩展到更大的群体，而无需依赖直接的参考人脸复制。
