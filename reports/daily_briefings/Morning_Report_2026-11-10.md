> ⚡ SplatAnything团队发现现有feed-forward 3DGS方法因高斯间距在不同场景尺度下差异大而导致监督信号模糊，为此提出GSNorm来归一化高斯间距，提供更一致的空间参考。这套方法在稀疏输入和极端视角下都实现了SOTA，对3D重建的跨场景泛化能力提升明显。
👤 Hao Yu, Zhenwei Wang | 📅 2026-11-05

**详情:** 我们指出了现有前馈3DGS方法的一个关键局限：高斯属性通常在径向距离归一化空间中进行预测，该空间对重建几何的全局径向统计量进行了规范化，而相邻高斯中心之间的间距在不同场景尺度和相机配置下仍可能大幅变化。这种不匹配会导致高斯尺度目标出现系统性偏移，从而产生模糊的监督信号。为解决这一问题，我们提出了SplatAnything，并引入高斯间距归一化（GSNorm），该方法对高斯间距的稳健场景级统计量进行规范化，从而为高斯预测提供更一致的空间参考。为严格评估我们的方法，我们进一步建立了一个系统性基准，涵盖多样化数据集、输入稀疏度水平以及具有挑战性的外推视角。大量实验表明，SplatAnything达到了最先进的性能，在场景尺度和视角发生显著变化时尤其表现出强劲的增益。

### 2. [Confucius4-R2T2: A Stable-Prefix Streaming ASR Model for Real Real-Time Transcription](https://arxiv.org/abs/2611.06043)
> ⚡ 网易有道团队推出 Confucius4-R2T2，通过冻结 Qwen3-ASR-1.7B 的音频编码器、仅用 1500 小时中英文数据后训练，让流式 ASR 的输出永不回改。这对翻译器和语音 agent 很关键——token 一旦被下游消费就无法撤回，稳定前缀意味着更少的无效计算和错误动作，且效果还能跨语言泛化。

**详情:** 流式语音识别正越来越多地被机器所使用，例如翻译器和语音代理，它们会在每个词元出现时立即对其进行处理。一个随后被修改的词元会导致无效的工作或错误的操作。在本工作中，我们提出了Confucius4-R2T2（Real Real-Time Transcription的缩写），一种稳定前缀流式ASR模型，它从不修改其先前的输出，同时保持高准确率和低延迟。R2T2通过在1，500小时的中英文音频上对Qwen3-ASR-1.7B进行后训练而获得，同时冻结其预训练的音频编码器和投影器。该适配基于最长稳定前缀（Longest Stable Prefix，LSP）的概念，这是我们在本工作中引入的新概念。我们证明了LSP在前缀序下是单调的、与全音频输出一致，并且在等于某个完整先前输出的标签中是极大的。从LSP标签中学习可将全上下文模型转换为稳定前缀流式模型，而无需任何架构更改。大量评估表明，R2T2使流式识别接近基模型的全上下文质量，同时以低发射延迟提供稳定的文本。其收益超越了后训练语言的范围，展示了从全上下文ASR到稳定流式的实用路径。我们在https://huggingface.co/netease-youdao/Confucius4-R2T2和https://github.com/netease-youdao/Confucius4-R2T2开源了模型权重和代码。

### 5. [LowRAM: Low-Rank Keys and Amortised Values for Composable KV Cache Compression at Test-Time](https://arxiv.org/abs/2611.07025)
> ⚡ 研究团队发现每个 attention head 内的 value 可由对应 key 高度预测，据此提出 value cache amortisation，并搭配 cross-layer 低秩 key 压缩组成 LowRAM 非对称压缩管线。该方法在 4 倍压缩下实现近无损和最高 5 倍 decode 吞吐，与量化、eviction 叠加后可达 26.9 倍压缩，说明把 key 和 value 当结构不同的对象来处理，是释放 KV cache 压缩空间的关键。
👤 Teresa Delgado, Hugo Hazard | 📅 2026-11-04

**详情:** 自回归解码依赖KV缓存，其内存占用随上下文长度线性增长，并限制了批处理大小和吞吐量。现有的后训练方法利用token、层和特征维度上的冗余，或降低数值精度。我们识别出一个互补的维度：在每个注意力头内，value在很大程度上可以从其对应的key预测出来。我们利用这一点进行value缓存摊销，在测试时为每个头拟合一个轻量级预测器，并仅为其重建效果最差的token存储残差，从而实现4倍近无损的value压缩。预测器可以通过元学习初始化以大幅减少预填充开销，或在允许一次性成本的场景下从头拟合，例如多查询推理。我们将value摊销与跨层低秩key压缩相结合，构建了LowRAM，一种非对称压缩流水线，在三个模型系列上均保持接近无损。通过在每个解码步骤仅重建选定的KV对子集，LowRAM可以将解码开销保持在最低水平，并在4倍压缩下实现最高5倍的峰值解码吞吐量。LowRAM还可进一步与量化和驱逐技术组合，在长上下文场景下达到26.9倍压缩，同时保持基线性能的94.5%。这些结果表明，将key和value视为结构上不同的对象，能够实现高效、激进且可组合的KV缓存压缩。

### 1. [GOPR-CAD: Graph-of-Operations Progressive Reasoning for CAD Generation](https://arxiv.org/abs/2611.11470v1)
> ⚡ GOPR-CAD 团队提出了一种基于 Graph-of-Operations 渐进推理的 agentic Text-to-CAD 流程，让 LLM 作为决策 agent 在封装好的 CAD 操作上逐步构建可执行操作图，再由确定性编译器生成最终模型。这个设计无需额外训练、可适配不同 LLM，直击当前 LLM 直接生成 CAD 代码时结构错误难以被察觉的痛点，在自建 MHCAD 基准上拿到 82.7% Structural Yield。
👤 Yitian Pang, Yifan Li | 📅 2026-11-08

**详情:** 生成精确的CAD模型需要大量工程专业知识，并对几何、拓扑和机械约束进行细致控制。文本到CAD旨在简化这一过程，但当前基于大语言模型的方法通常直接生成CAD程序。语言模型在生成较长代码时仍不可靠，尤其是在协调耦合的几何、拓扑和尺寸约束方面。因此，可执行程序仍可能生成结构不正确的模型，而执行率和渲染外观可能无法揭示这些问题。为解决这些局限，我们提出GOPR-CAD，一种基于操作图渐进推理的智能体式文本到CAD流水线。语言模型作为封装CAD操作上的决策智能体，逐步构建可执行的操作图，再由确定性编译器转换为最终CAD模型。这种分离无需额外训练，并支持不同的语言模型。为评估结构保真度，我们构建了MHCAD，一个包含300项标准机械零件需求的基准，这些需求源自《机械设计手册》。其显式结构使得无需参考的STEP/B-rep评估成为可能。GOPR-CAD在MHCAD上达到82.7%的结构产出率，在外部CADPrompt子集上达到87.2%的结构产出率。

### 2. [Model-assisted semi-supervised estimation of the Mann-Whitney probability under right censoring](https://arxiv.org/abs/2611.11456v1)
> ⚡ 研究团队针对右删失场景下的全生命周期Mann-Whitney概率，提出了一种半监督估计方法，利用仅含协变量的辅助样本配合少量标注数据来提升估计精度。这项工作的重要意义在于，它给出了估计量的一致性和渐近正态性保证，并量化了辅助样本规模带来的方差缩减效果，为标注数据昂贵时的生存分析比较提供了实用方案。
