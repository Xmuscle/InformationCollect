**详情:** 学习动态文本属性图（DyTAGs）的可迁移表示，要求模型能够捕捉跨领域持续存在的底层交互动态。然而，现有方法往往过度拟合领域特定的结构、时间和语义模式，限制了分布偏移下边分类的性能。为揭示并解决这一问题，我们正式建立了一种用于DyTAGs边分类的留一领域（LODO）迁移学习协议。在该协议下，我们证明，当前最先进的动态图学习自监督方法在迁移到未见领域时表现不佳。令人惊讶的是，现有方法的表现甚至不如我们提出的一种在结构和时间上无感知的事件袋（BoE）模型，该模型仅输入节点和边文本特征的无序序列。从BoE出发，我们提出了时空语义对齐（STSA），它集成了一种时空编码器，将时间增量和节点出现频率的表示融合到一个统一流形中。STSA以对比语义预测目标进行训练，该目标将边表示锚定到由预训练语言模型初始化的多领域文本潜在空间，提供了一个优于BoE和我们所评估的所有现有方法的鲁棒先验。

### 1. [PReCache: Efficient KV Cache Sharing for Multi-LoRA Agents via Low-Rank Precomputation and Neutral Reconstruction](https://arxiv.org/abs/2609.34054v1)
> ⚡ PReCache 团队提出了一套免训练的 KV cache 共享框架，通过 PreLRShared 和 ReBaseShared 两种设计，让多 LoRA agent 系统在长任务中不再重复 prefill 共享轨迹。它在多个模型和 agent benchmark 上实现了最高 3.1 倍的 TTFT 加速和 2.3 倍的单请求吞吐提升，同时 ReBaseShared 把精度损失压到平均仅 1.1 分，算是多 agent 推理效率与角色专精之间一个挺漂亮的平衡。
👤 Hyesung Jeon, Hyeongju Ha | 📅 2026-09-28

**详情:** 多LoRA智能体系统通过共享一个公共骨干模型来实现高效的角色专业化。然而，每个智能体都会重复处理不断增长的共享轨迹并构建自己的KV缓存，在长时程任务中引入了大量的内存和计算冗余。现有的KV缓存共享方法减少了这种重复预填充，但它们要么需要额外训练或架构约束，要么保留了大量的模型计算。此外，直接复用缓存会导致当前智能体依赖于前一个智能体的适配器所生成的缓存状态，从而削弱其自身LoRA所编码的角色特定行为。我们提出了PReCache，一个无需训练的KV缓存共享框架，包含两种设计，即PreLRShared和ReBaseShared，它们共享使用预训练权重计算的基础缓存，并预计算一个紧凑的智能体特定低秩（LR）缓存。为消除重复预填充，PreLRShared在共享上下文首次处理时为每个智能体预计算其LR缓存，使当前智能体无需重新处理前序智能体已处理的上下文即可使用自己的LR缓存。为提高共享准确性，ReBaseShared从无适配器的隐藏状态中重建共享基础缓存，减少由前序智能体适配表示所引起的残余误差。为最小化其重建开销，我们提出了两种推理方案，分别针对单流推理和并发服务，分别在每个智能体轮次结束后或与其执行同时进行相同的重建。在多个模型和智能体基准测试中，PreLRShared相比无KV缓存共享的推理实现了最高3.1倍的TTFT加速和2.3倍的每请求吞吐量提升。在所评估的缓存共享方法中，ReBaseShared总体上最能保持准确性，相对于无缓存共享的推理平均仅下降1.1个点。
