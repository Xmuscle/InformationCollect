### 1. [AgentSSL: Can MLE Agents Leverage Unlabeled Data?](https://arxiv.org/abs/2611.17323v1)
> ⚡ 研究团队提出AgentSSL，把半监督学习（SSL）重构为程序搜索问题，让MLE agents在标注数据稀缺的场景下自动合成并组合已有SSL技术。值得注意的是，即便反馈信号很弱，agent在12个设定中有8个超过最强人工基线，最高提升21.8%，但程序选择成了关键瓶颈——按agent反馈指标选程序时性能最多掉47%，团队为此推出ProgramSelectBench（含16,977个SSL程序）来系统评估选择方法。
👤 Ethan Lin, Akanksha Sarkar | 📅 2026-11-12

**详情:** 将机器学习系统应用于新领域会在标注数据获取和人工流程工程两方面引入瓶颈。尽管近期的MLE智能体在自动化流程设计方面展现出前景，但它们几乎仅在完全监督的设置下被研究，因而在标注数据稀缺但无标注数据丰富的现实场景中尚未得到检验。在本工作中，我们提出智能体半监督学习（AgentSSL），将SSL构建为程序搜索问题，并研究智能体在有限监督下如何在该空间中导航。我们发现，即使在弱反馈和匹配计算量的条件下，智能体也能合成结合并适配已有SSL技术的代码，在12个设置中的8个上超越最强的人工工程基线，最高提升达+21.8%。然而，我们的结果识别出程序选择是AgentSSL中的一个关键瓶颈，当基于智能体的反馈指标进行选择时，性能下降幅度高达47%。为系统性地研究这一瓶颈，我们引入ProgramSelectBench，这是一个大规模基准，包含总计16,977个智能体生成和人工工程的SSL程序，并评估无监督和主动程序选择方法。我们进一步在真实世界的生态检测任务上评估AgentSSL，突出了将智能体发现的策略迁移到受控基准之外所面临的机遇与挑战。

### 2. [CoReMem: Cost-Internalizing Memory for Successive Coding Tasks with Prospective Valuation](https://arxiv.org/abs/2611.17316v1)
> ⚡ 研究团队推出 CoReMem 框架，让 coding agent 在未知下一任务前就学会权衡 memory 的读写成本，用“锚点”（仓库位置与可执行检查）构建紧凑记忆。它在 ChainSWE 上把 27B actor 的解决率从 21.0% 提到 25.7%，还少用 17% 步数和 11% token——说明给 agent 设计 memory 时，算清成本账比一味多存更划算。
👤 Peiwen Li, Harshit Verma | 📅 2026-11-12

**详情:** 编码智能体在持续演化的代码仓库上处理接连不断任务，在下一个任务未知之前就传递编辑并写入记忆。为未知的后续任务选择记忆，需要在未来有用性与写入和读取记忆的成本之间取得平衡。行动者还必须判断，随着任务展开，何时依据可用记忆采取行动能够节省精力。我们提出代码仓库记忆（CoReMem），这是一个成本内化框架，通过衡量记忆在下一任务上的价值来指导记忆设计和行动者适配。前瞻性片段估值在相同的继承仓库状态下，比较有和没有单个轨迹片段时下一任务的运行情况，从而指导构建围绕锚点的紧凑记忆：锚点即仓库位置和可执行检查。行动者适配在 rollout 组内估计有记忆和无记忆时的同策略记忆价值，使用一种在成功运行中优先考虑问题解决并惩罚步数的奖励。来源门控价值信用将额外价值项分配给被识别为使用记忆提供的锚点的步骤，同时每一步都保留结果信用。在 ChainSWE 上，CoReMem 将 27B 行动者的问题解决率从 21.0% 提高到 25.7%，相对于没有记忆的未训练行动者模型，步数减少 17%，总缓存感知 token 数减少 11%，其中包括记忆模块调用。

### 3. [Sketching Language Models for Context Attribution](https://arxiv.org/abs/2611.17313v1)
> ⚡ 研究团队提出了一种基于sketching的算法，能在稳定性假设下用O(√log(1/ε)/ε)次模型调用估算LLM所有leave-one-out归因值，并证明了匹配的下界。关键在于将前向微分应用于反向传播电路而非直接套用原方案，大幅降低了方差和评估开销。这意味着context attribution的实用化成本有望显著下降，对LLM可解释性工具落地是个实打实的推进。
👤 Christopher Liaw, Aranyak Mehta | 📅 2026-11-12

**详情:** 上下文归因研究的是移除提示词的部分内容会如何改变语言模型的输出。我们针对包含$n$个token的提示词和固定测量函数，研究留一法（LOO）归因。直接计算所有LOO值需要$n$次模型评估。在稳定性假设下，我们的算法以恒定概率将所有LOO值估计到与$\varepsilon$成正比的误差，所需评估调用次数为$O(\sqrt{\log(1/\varepsilon)}/\varepsilon)$。为补充我们的上界，我们在预言机模型中证明了评估调用次数上匹配的$Ω(\sqrt{\log(1/\varepsilon)}/\varepsilon)$下界。在实验上，我们验证了与稳定性一致的系数衰减，并在一个小型语言模型检索任务上评估了我们的草图算法的性能。在技术上，我们的结果基于一种针对算术电路的草图算法，其泰勒系数满足Gunn [Gun26]最近引入的稳定性条件。直接改编其前向微分草图将需要$\widetilde{O}(\log(n)/\varepsilon^2)$次评估调用。我们的关键观察是，我们可以将前向微分应用于反向传播电路，相对于相同泰勒阶数的前向草图仅带来常数开销。这降低了草图的方差，是我们改进评估界的关键。我们的下界建立在Amsel、Chen、Duman Keles、Halikias、Musco和Musco [ACDH+26, SIAM Journal on Matrix Analysis and Applications]的技术之上，该技术用于下界估计随机矩阵对角元素所需的矩阵-向量查询次数。

### 4. [Classical Energies Learn to Reason 1,000x Faster than Looped Models](https://arxiv.org/abs/2611.17309v1)
> ⚡ CRAM 团队用80年代 Hopfield & Tank 的能量模型搞出了一个叫 CRAM 的学习版本，在单块 GPU 上仅训练 42ms 和 132ms 就分别解出 Sudoku-Extreme 的 99.996% 和 Maze-Unique 的 100%，比 looped models 快至少 1000 倍。这意味着能量方法可能是从数据中训练推理的一条极有前景的路线，同时也提醒别再用 Sudoku、Maze 这类过于简单的 benchmark 来测 looped 推理技术的扩展性了。
👤 Benjamin Hoover, Hugh Blayney | 📅 2026-11-12

**详情:** 循环模型已成为推理的一种重要范式，在数独-极端和迷宫-唯一等简单推理谜题上取得了成功。然而，这些模型可能不稳定、训练缓慢，并且需要大量参数和浮点运算来解决简单的谜题。在能量函数上进行下降不仅缓解了这些问题，还提供了优势：内置的早停机制、随问题难度自适应调整的计算量、无需通过求解器进行微分即可快速训练，以及可解释的权重能够学习谜题的约束条件。在此，我们通过学习版本的Hopfield &amp; Tank八十年代提出的能量函数来证明这一点，我们将其称为CRAM，在单块GPU上训练42毫秒和132毫秒后，分别解决了99.996%的数独-极端测试谜题和100%的迷宫-唯一测试谜题，在这些任务上至少比循环模型快1，000倍。CRAM在数独-极端上以至少少282倍的推理浮点运算量达到了基线循环模型的最高准确率。我们的工作表明两点。第一，能量函数是從数据中训练推理的一个极具前景的方向。第二，对使用数独和迷宫等可轻易求解的基准来测试循环推理技术的可扩展性提出了警示。

### 5. [Consistent Video-to-Video Translation via Explicit Correspondences](https://arxiv.org/abs/2611.17298v1)
> ⚡ vid2vid-long 团队提出了一种基于对应关系的方法，通过在输入视频中计算 patch-level 对应关系来检索已生成的输出区域，并用 correspondence cross-attention 对模型进行条件化。这解决了固定长度因果窗口导致的长程一致性瓶颈，在保持实时性和生成质量的同时显著提升了长视频的时序一致性。
👤 Gaurav Parmar, Zhengqi Li | 📅 2026-11-12

**详情:** 交互式视频到视频应用需要实时生成，同时保持长程时间一致性。然而，近期方法通过将注意力限制在固定长度的因果窗口内来实现速度。当相关历史落在上下文窗口之外时，这限制了长程一致性。为解决这一局限，我们提出了vid2vid-long，一种基于对应关系的方法，其建立在一个简单观察之上。视频到视频翻译提供了显式的跨帧参考：输入视频中匹配的区域在输出视频中也应当匹配。具体而言，我们在输入中计算块级对应关系，指导对相应区域中先前生成输出的检索，并通过对应交叉注意力将这些块作为模型的条件。我们的实验表明，vid2vid-long在近期视频模型上持续改善长程时间一致性，同时保持生成质量和实时性能。

### 1. [Internalizing Investment Mandates: A Neurosymbolic RL Approach to Portfolio Allocation](https://arxiv.org/abs/2611.17329v1)

👤 Zeynep Yıldız, Satchit Chatterji | 📅 2026-11-12

**详情:** 机构投资组合依据投资政策声明运作，该声明规定了资产配置约束，且往往以市场状态信息为条件。深度强化学习已被证明能够优化财务表现，但通常无法强制执行规则合规，因而难以适用于现实部署。现有的神经符号方法，如概率逻辑策略梯度（PLPG），通过可微符号监督提供满足约束的强化学习（RL），但其假设动作空间为有限离散空间。我们提出一种受PLPG启发的连续配置方法，该方法利用重参数化蒙特卡洛采样估计策略自身执行动作满足投资授权的概率，并将其加入训练目标。推理阶段不设任何事后强制执行机制来拦截动作，合规性由智能体学习获得。直接对未经修正的确定性平均动作进行审计，该策略将违反六规则状态条件授权的比例从无约束RL的96-98%和奖励惩罚基线的33.4%降至4.8%，表明连续动作神经符号策略能够实质性内化符号化授权。
