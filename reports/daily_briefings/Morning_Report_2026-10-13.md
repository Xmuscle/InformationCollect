### 1. [S-Space: Exploring Spatial Workspace in Multimodal Language Models](https://arxiv.org/abs/2610.13527)
> ⚡ 多模态大模型（MLLMs）内部其实藏着一个叫 S-Space 的线性子空间，专门用物体 token 的激活来编码水平、垂直和距离坐标——而且这玩意儿是模型自带的，不靠特定 prompt 触发。这意味着 MLLMs 已经能形成不错的空间表征，但真正的瓶颈在于视角变换时的空间推理计算，这为诊断和提升空间智能指了条明路。
👤 Zhiyuan Shi, Xiang Li | 📅 2026-10-09

**详情:** 多模态语言模型（MLLMs）展现出颇具前景的空间推理能力，但支撑其能力的内部机制仍鲜为人知。我们揭示了S-Space，这是一个线性表示子空间，其中物体token表示沿水平、垂直和距离轴编码连续坐标。尽管我们通过将空间答案分数对物体token激活进行微分来识别这些轴，但S-Space是内在的，而非由特定数据或提示诱导产生，在非空间问题下仍可读取。我们表明，S-Space充当MLLMs的内部空间工作区。感知将物体位置编码其中，形成可直接读取以支持准确空间判断的空间表示。内部推理对其进行变换以适应视角变化。言语反应选择性地访问它，因果干预实验证明了这一点——干预改变了空间判断，同时在很大程度上保留了非空间反应。案例研究进一步表明，S-Space能为未见过的实体和观察者分配位置，并将物理方向与抽象语言意义相连接，这既暗示了大规模语言训练的能力，也揭示了其局限性。最后，我们将S-Space用作空间推理失败的诊断工具。方向词读出揭示了基本方位与图像相对参考框架之间的系统性耦合。更重要的是，感知-计算分解暴露了一个关键瓶颈：MLLMs能够形成有能力的空间表示，但在跨视角变化进行可靠推理所需的空间变换方面仍存在不足。

### 2. [DiffusionART: Efficient, Stable and Scalable Reinforcement of Diffusion Models](https://arxiv.org/abs/2610.12572)
> ⚡ DiffusionART 团队提出了一种新的在线 RL 微调方法，通过把每个 prompt 的奖励聚合成统一方向并加 trust-region 二次更新，绕开了 Flow-GRPO 的信用分配瓶颈和 DiffusionNFT 对 EMA 调参的依赖。它在 HunyuanVideo-13B 上以少 12 倍的 GPU 时间追平甚至反超对手，意味着扩散模型 RL 微调终于有望摆脱逐任务调参的苦力活。
👤 Zhenglin Wan, Jiayu Chen | 📅 2026-10-08

**详情:** 在线强化学习（RL）通过黑盒奖励对扩散模型进行微调，但Flow-GRPO等逆向过程方法因信用分配不佳而效率受限，而DiffusionNFT等前向过程方法虽然高效，却因需要精心调参的指数移动平均（EMA）离策略训练而不稳定。我们表明，NFT风格的目标函数包含一种隐藏的前向–逆向一致性力，联合正–负训练只能部分抵消该力，而EMA是通过恢复而非离策略 rollout 来稳定训练的。我们提出DiffusionART（Diffusion Reinforcement with Aggregation-First Reward Tilting），它将每个提示词的奖励聚合为逆向过程状态的共享奖励改进方向，从构造上消除了该一致性力，并添加了信任域掩码的第二次更新，以实现漂移自适应恢复，无需EMA调参。它不需要可微奖励模型，在每提示词样本更少的情况下仍然有效，并支持成对奖励模型（DiffusionART-Pairwise）。在图像和视频生成中，DiffusionART无需逐任务调参即可高效稳定地训练。特别是在HunyuanVideo-13B上，在视觉和运动质量奖励等权重的条件下，DiffusionART分别以少12.02倍和11.72倍的GPU小时数达到DiffusionNFT和Flow-GRPO-Fast的后期平均奖励水平，同时平均训练奖励分别高出28.8%和53.0%。

### 3. [Reflex: Visually Grounded Reactive Humanoid Control](https://arxiv.org/abs/2610.12772)
> ⚡ 斯坦福团队搞了个叫Reflex的三阶段框架，让Unitree G1人形机器人学会用全身接住抛来的箱子，仅靠自视角RGB-D感知就能在仿真里达到85.7%的成功率。这意味着人形机器人终于开始具备类似人类的视觉反射式全身控制能力，在2.5米和5米距离上实战成功率已达人类接球手的76%和59%。
👤 Taoyang Jia, Weikai Huang | 📅 2026-10-08

**详情:** 人类能毫不费力地对世界做出反应：他们能娴熟地回击网球、接住掉落的杯子、避让经过的推车，或在卡车卸货时接住抛来的箱子。这些日常动作需要在约一秒内预判移动目标并以全身做出反射性响应。这种视觉反应式全身控制对人形机器人而言仍具挑战性，因为它们必须（1）协调全身控制，（2）实时响应物体动力学，（3）将感知建立在自我中心视觉之上。我们将接住抛来的箱子作为一项代表性任务加以研究，该任务对上述三项能力均有要求；现有系统仅覆盖其中一部分，依赖末端执行器、动作捕捉或标记物体。我们提出Reflex，一个三阶段框架，通过物体动力学的紧凑表示将各阶段连接起来，逐阶段学习这些能力。首先，基于状态的策略通过强化学习学会全身接取。其次，该策略学会从延迟且不完整的观测中推断移动箱子的动力学。第三，一个自我中心RGB-D编码器学会在保持全身控制器固定的情况下，直接从视觉观测中恢复该动力学表示。这种分解为每种能力提供了直接的训练信号，并使视觉学习显著更具可扩展性。在仿真中，Reflex从自我中心RGB-D实现85.7%的接取成功率，而在给定特权箱子观测时为87.9%。时间视觉历史至关重要：移除它会使居中抛掷和横向偏移抛掷的成功率分别下降35.6和39.8个百分点。在真实的Unitree G1上，Reflex在2.5米和5米处接住人类抛出的箱子，成功率分别为65%和40%，达到人类接取者在相同距离下成功率的76%和59%。

### 4. [SoftwareGym: Scaling Computer-Use Agent Training with Diverse Synthesized Software Environments](https://arxiv.org/abs/2610.12611)
> ⚡ 面对CUAs训练环境稀缺的瓶颈，研究团队推出SoftwareGym，一个自动合成多样化GUI软件环境的pipeline，生成了182个可运行应用并配套120项评测集SoftwareGym-Bench。用它训练出的CUA在严格域外的OSWorld上Pass@3从41.39%跃升至56.97%，说明合成环境能作为可扩展、可迁移的监督信号，这路子挺有戏。
👤 Tian Jin, Wenhao Wang | 📅 2026-10-08

**详情:** 计算机使用智能体（CUA）正在快速进步，但大规模合成多样化且可靠的软件环境仍然具有挑战性。原生应用环境需要大量的构建和集成工作，这限制了应用覆盖范围并增加了应用特定过拟合的风险。浏览器托管环境提供的交互深度和工作流复杂度有限。这些局限性促使了SoftwareGym的出现，这是一个自动化流水线，用于合成具有多样化界面、可执行功能和运行时验证行为的GUI软件环境。它生成结构多样化的设计，将其实现为可运行的应用程序，并使用GUI评估与迭代修复来确保功能可靠性。利用SoftwareGym，我们合成了涵盖十二个类别的182个应用程序，并实现了91.5%的平均GUI任务通过率。我们构建了SoftwareGym-Bench，一个涵盖相同十二个类别的120任务评估套件，并使用从这些环境中收集的轨迹进行CUA训练。所得模型在严格的域外OSWorld基准上将Pass@3从41.39%提升至56.97%，并在SoftwareGym-Bench上达到40.0%。这些结果展示了合成软件环境作为CUA训练的可扩展且可迁移监督信号的潜力。

### 5. [Can AI Agents Learn Their Way to the Top? Evaluating Heuristic Learning in a Long-Running Game Agent Competition](https://arxiv.org/abs/2610.12341)
> ⚡ AI agents 正被当作「学习引擎」来改写游戏策略：团队提出 Adversarial Heuristic Learning（AHL）范式，并发布 AAArena 基准，涵盖 12 款真实对抗游戏和 1,920 份人类程序，让 agent 在固定预算下自行选对手、看 replay、改代码。实测 Opus5.5 + Claude Code 拿下 6 枚金牌，但另外 6 款人类天梯仍无人攻破，说明 LLM 在复杂规则理解与长程策略上还有硬骨头要啃。
👤 Kaisen Yang, Qingle Liu | 📅 2026-10-08

**详情:** 对抗性游戏推动了从启发式搜索到强化学习的进步，然而从有限样本中学习和适应策略仍然具有挑战性。AI智能体提供了一种替代方案，将游戏经验转化为可执行策略的修正。在启发式学习（HL）的基础上，我们形式化了对抗性启发式学习（AHL），这是一种利用AI智能体作为学习引擎来优化游戏策略和支持软件，同时保持模型权重不变的范式。我们引入了AAArena，一个包含12款真实对抗性游戏和1，920个存档人类程序的基准测试，其评估协议模拟了真实世界的游戏竞赛。智能体解读规则、选择对手、分析回放，并修改游戏智能体，以在固定的对局和评估预算内实现其最高排名。我们评估了完整模型和框架配置：Opus5.5配合Claude Code获得6枚金牌，而没有任何被评估的配置能够登顶其余6个人类排行榜。在规则规范更复杂的游戏中，表现通常较弱。进一步实验表明，对手选择和密集反馈支持策略改进，并且智能体既从自身对局的同策略回放中学习，也从其他玩家对局的异策略回放中学习。这些结果凸显了HL在对抗性游戏中的潜力，并指出了在游戏理解、策略实现和长时程策略开发方面持续存在的挑战。

**详情:** 在本文中，我们研究基于物理的铰接式3D资产生成——将目标从复现物体的外观转向捕捉它们如何运动和运作。受程序化生成和智能体生成文献的启发，我们提出了Artisan，一个扩展了最新方法Articraft的系统，通过引入带有物理仿真反馈的多智能体流水线，实现了超越几何、外观和物理合理的铰接关系之外的全面属性，例如无碰撞运动、重力下的稳定性以及准确的质量和材料属性。此外，我们构建了一个涵盖四个关键方面的统一基准：空间保真度、物理合理性、下游任务性能和整体质量。该基准包含来自ArtVIP和LightWheel的100个参考资产、50个稳定性提示以及50个带有参考质量的ABO物体，并通过评估协议对各种指标进行评测。通过对10余个代表性模型的广泛评估，Artisan在取得有竞争力的空间保真度的同时，在所评估方法中实现了最低的碰撞率和最高的稳定率。我们的系统和基准共同为推进3D生成向物理合理、功能可用的资产方向发展提供了洞见。
