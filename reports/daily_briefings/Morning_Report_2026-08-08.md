### 1. [Learning When to Trust via Selective Context Preference Optimization](https://arxiv.org/abs/2608.06377v1)
> ⚡ MIST团队发布了一个名为SC2W的配对指标，专门衡量误导性信号如何将原本正确的答案翻转成错误，并基于此提出SCOPE优化方法，通过平衡四类条件的DPO训练来降低模型的易受骗性。这项研究揭示了一个关键问题：单纯训练模型抵抗误导信号会陷入“全盘忽略上下文”的陷阱，而真正该做的是选择性信任——在保留对有效上下文依赖的同时，识别并拒绝误导信息。实验表明，该方法在不牺牲干净、正确或无关上下文处理能力的前提下，显著降低了主流开源模型的SC2W分数。
👤 Xian Sun, Wei Chow | 📅 2026-08-06

**详情:** 语言模型日益依赖外部信号来形成其答案，而一个具有误导性的信号就足以将原本正确的回答转变为错误。显而易见的补救措施——训练模型抵抗此类信号——却隐藏着一个失效模式：一个忽略所有上下文的模型看似稳健，但在上下文值得信赖时却毫无用处。我们将这一问题重新定义为选择性信任，并引入了MIST——一个由人工标注的基准数据集，它在四种匹配条件下呈现每个推理项目（清晰、误导性、正确上下文和无关上下文），同时提出SC2W——一种配对度量指标，用于统计误导性信号将清晰正确的答案转变为错误答案的频率。通过一项全面的基准研究，我们观察到这种易感性是普遍存在的。随后，我们提出了SCOPE方法，该方法挖掘清晰正确/误导性错误的失败案例，并在所有四种条件下均衡配对的偏好对之上优化标准的直接偏好优化（DPO）目标，而非仅针对误导性项目进行优化。我们的方法在显著降低主流开源模型SC2W指标的同时，保持了在添加上下文为清晰、正确或无关时模型的准确性。通过这项工作，我们主张模型应依据选择性信任来评判，而非仅凭抵抗能力。

### 4. [An Optimal Agnostic PAC Algorithm](https://arxiv.org/abs/2608.06363v1)
> ⚡ Han等人构造了一个有限VC维假设类上的新学习器，其经验风险最小化达到统计最优界，常数项为7×10^8。这首次在固定L*下匹配了Devroye等人的下界，彻底解决了agnostic PAC学习的样本复杂度问题，意味着无需额外假设就能实现最优收敛速率。
👤 Markus Engelund Mathiasen, Jian Qian | 📅 2026-08-06

**详情:** 设 \(H\subseteq\{-1,+1\}^X\) 为一个有限VC维 \(d\ge1\) 的函数类。记 \(L\) 为二元风险，且 \(L^*=\min_{h\in H}L(h)\)，我们构造了一个学习器，其达到统计最优的风险界：对于来自容量为 \(n\) 的独立同分布样本，对每个 \(0<\delta\le 1/2\)，以至少 \(1-\delta\) 的概率有 \[ L(\widehat h) \le L^*+ 7\cdot10^8\left( \sqrt{\frac{L^*(d+\log(1/\delta))}{n}} +\frac{d+\log(1/\delta)}{n} \right). \] 这解决了在任意固定 \(L^*\) 下，至多相差普适常数的不可知PAC学习的样本复杂度问题，与Devroye、Györfi和Lugosi [《模式识别的概率理论》，Springer，1996] 的下界相匹配。

### 5. [AV-AIVAT: 74x Cheaper Agent Evaluation with Certified Anytime-Valid Stopping in Imperfect-Information Games](https://arxiv.org/abs/2608.06362v1)
> ⚡ AIVAT团队将方差缩减技术与置信序列结合，推出了 anytime-valid AIVAT（AV-AIVAT），让智能体评估能在证据充分时立即停止，无需预设预算。这一方法在15种LLM智能体配置、71,439手HUNL对局中实现中位54倍方差缩减，原始结果需74倍手数才能达到同等停止精度。它既支持渐近筛选，又提供精确有限样本认证，使评估既高效又可审计，第三方能随时复核停止时的结论。
👤 Boning Li, Yu Chen | 📅 2026-08-06

**详情:** 判断两个智能体孰强孰弱，意味着要进行博弈，直至技巧胜过运气，而每一局博弈都耗费金钱、模型推理或专家时间。由于所需博弈局数未知，固定预算的评估要么在结果已定后继续投入，要么在智能体尚无法区分时便提前终止，而采用普通置信区间的朴素可选停止法则会使既定显著性水平失效。我们使此类评估在其证据充分的那一刻即刻停止，且保证依然有效。行动知情价值评估工具（AIVAT）通过条件均值零修正降低了不完美信息博弈中的方差，在涵盖71，439手配对单挑无限注德州扑克（HUNL）的15种LLM智能体配置中，其中位数缩减达54倍，但该工具并未说明何时停止。我们将AIVAT与持续监测的置信序列（CSs）相结合，提出任意时点有效的AIVAT（AV-AIVAT），其在线价值模型仅从过往博弈中学习，从而确保没有任何一局博弈为其自身修正打分。在名义95%的置信水平及±1大盲注的目标精度下，原始结果在渐近置信序列（AsympCS）下停止所需的手数中位数是经AIVAT修正结果的74倍。精确的有限样本认证采用经验-伯恩斯坦置信序列（EB-CS），该序列需要对修正后收益有一个独立验证的界。我们针对Leduc德州扑克从结构上建立了这样一个界，并刻画了由CS的赌注上限及该界共同决定的宽度下限，该下限决定了方差收益中有多少能转化为更早的停止；描述性的HUNL EB-CS运行显示，停止时间比的中位数为1.37倍。AV-AIVAT将方差缩减转化为高效、可审计的早期停止，同时将渐近筛选与精确认证相分离，从而使评估能在证据充分的那一刻停止，并向第三方移交在那一停止时刻重新核查结论所需的一切材料。

### 1. [The Bitter Lesson of Tool Calling](https://arxiv.org/abs/2608.06370v1)
> ⚡ OpenAI 等团队在 BFCL v4 基准上对比了 14 个 LLM 的两种工具调用方式，发现用 Python 脚本（programmatic tool calling, PTC）替代传统 JSON 调用，在 11 个模型上表现持平或更优，GPT-5.6 家族更是提升了 10.6%。这打破了 JSON 作为工具调用标准的惯性，尤其在并行扇出和上下文退化场景下更稳定，说明代码化调用正成为更自然的 agent 交互范式，值得关注。
👤 Ishan Patel, Sahil Sen | 📅 2026-08-06
