### 1. [Gacha Decoding: Eliciting Diverse Generations Through Instruction Following](https://arxiv.org/abs/2610.01382v1)
> ⚡ Gacha Decoding 这个 inference-time 方法把多样性当成 instruction-following 问题来做，用外部 RNG 工具配合 LLM 的指令遵循能力来识别和实现不同的 response mode，在开放域任务上比现有方法最多提升 2.4x Vendi 分数，还能用少一个数量级的样本找到同样多的高质量 mode。更有意思的是，它反转了多样性和模型能力之间的老矛盾——模型越强，Gacha 的多样性反而越好，而 token entropy 和传统方法的多样性却在下降。
👤 Scott Geng, Yufei Zhang | 📅 2026-10-01

**详情:** 我们提出了Gacha Decoding，一种在推理阶段激发语言模型多样化生成的方法，其效果随模型能力的提升而扩展。在开放式领域（真实场景对话、创意写作、图像生成规划以及蛋白质设计）中，Gacha Decoding在同等质量下显著优于现有的生成多样性方法（Vendi指标最高达到次优先前方法的2.4倍），以少一个数量级以上的样本量（11.0倍）达到相同数量的高质量模态，并发现了其他方法均无法揭示的新颖模态。我们的核心洞见是将多样性视为一个指令遵循问题：我们不依赖语言模型的token熵，而是将其指令遵循能力与来自外部随机数生成工具的随机性相结合，从而可扩展地识别并实现响应空间中不同的模态。这种“以骰子规划”的方法使Gacha能够逆转长期以来观察到的多样性与模型能力之间的张力。随着底层语言模型成为更好的指令遵循者，Gacha Decoding下的多样性持续提升——即便其token熵以及先前方法下的多样性在下降。总之，我们的结果表明，指令遵循——而非仅仅token熵——能够驱动生成多样性。

### 2. [Generation Provenance Before Behavior Attribution: Auditing Synthetic Speech Research Objects](https://arxiv.org/abs/2610.01378v1)
> ⚡ 一个研究团队提出「生成溯源基底」（generation-provenance substrate），把合成语音的源规格、波形、目标、事实清单和不可变清单身份绑定成可审计单元，并在日本护理交接场景的113条合成语音上做了审计。这为合成数据的行为归因划出了候选因果图和审计边界，但作者强调溯源只是必要条件——真正归因仍需冻结训练运行和干预证据。
👤 Sidi Chang, Peiying Zhu | 📅 2026-10-01

**详情:** 将模型行为归因于合成训练数据，需要先知道每个训练条目是由什么生成的，然后才能估计该条目造成了什么影响。波形-标签对并不保留这一知识。我们提出一种生成溯源基底，其中合成研究对象绑定源规格、生成内容、波形、目标、事实要求、质量信号、审核谱系以及不可变清单身份。生产者和选择机制决定证据意义；存储位置和变量名则不然。我们在一个私有的日本护理交接流水线中审计该基底。一个包含113个资产的审核总体涵盖六个场景族、共计1.552小时的合成语音；所有条目都具有关联音频、转录文本、候选记录和事实核查清单，但人类证据具有选择性和来源特异性。两个仅保留忠实样本的清单在场景种子层面互不重叠，并具有不可变版本，而精确的上游归因仍然受阻于浮动的生成器别名、缺失的逐片段TTS和代码戳记，以及未版本化的检查提示。我们认为，生成溯源对于行为归因是必要的，但并不充分：它定义了候选因果图和审计单元，而贡献性归因仍然需要冻结的训练运行以及干预或影响证据。本文贡献了一个紧凑的溯源契约、一个审计协议，以及一个针对合成数据归因的有界案例研究；可提供受控研究访问，但我们不声称因果训练数据归因、临床有效性或无限制公开发布。

> ⚡ 工厂正转向小批量高定制生产，研究团队为此提出让每个产线模块搭配专属 LLM-based agent 与 MCP tool server，通过 OPC UA 和 MQTT 协同编程。在六模块仿真工厂中，monolithic 与 peer-to-peer 架构均达 93% 平均解决率，orchestrator 还能自主绕过静默传送带故障，证明这套方案可作为 LLM 编程智能制造的通用底座。

**详情:** 工厂正朝着更小批量、高度产品定制化的方向转变，这要求对灵活且可重构的自动化系统进行频繁的重新编程。基于LLM的智能体可以部署在两种互补的角色中：离线时，它们生成确定性的生产序列，减少编程工作量；在线时，它们操作实际机器并处理静态程序无法预见的运行时故障。我们提出一种解决方案，其中每个工厂模块都配有一个专用的基于LLM的智能体和一个MCP工具服务器，该服务器通过OPC UA方法调用暴露模块的技能，智能体之间通过MQTT进行协调，并依靠工厂状态的实时更新进行 grounding。我们在一个物理六模块六边形工厂的仿真中，针对九个复杂度递增的生产挑战比较了三种智能体架构（编排器、点对点和单体式），其中包括静默硬件故障检测。单体式和点对点架构均达到了最高的平均求解率（93\%），而编排器架构通过自主将板件绕开被阻塞段进行改道，在全部十次运行中唯一解决了静默传送带故障。所有架构都表现出涌现式故障诊断行为，而无需任何显式的故障处理逻辑，从而确立了标准化MCP工具、基于MQTT的智能体间通信以及实时状态注入作为LLM编程智能制造的可行的且可复现的基础。

### 4. [Fold'EM: Direct atomic structure inference from Cryo-EM particles](https://arxiv.org/abs/2610.01358v1)
> ⚡ 一个团队搞出了 Fold'EM，直接把蛋白质生成模型的先验和 cryo-EM 粒子图像结合，跳过密度重建和建模两步，从少量单颗粒图像就能推断出原子结构。这意味着低样本量下的结构解析和稀有构象表征可能变得更快更省，对 heterogeneous 样本尤其有吸引力。
👤 Advaith Maddipatla, Märt-Erik Mäeots | 📅 2026-10-01

**详情:** 单颗粒冷冻电子显微镜（cryo-EM）已成为一种广泛采用的生物分子结构测定技术。传统的冷冻电镜计算流程首先将大量颗粒图像合并以重建静电势（ESP）图，然后将原子模型拟合到所重建的图中。密度重建具有高样本复杂度，需要大量颗粒图像，使得结构测定成本高、通量低，对于异质性样本尤其如此。反过来，随着重建图分辨率的下降，下游的原子模型构建变得越来越困难。蛋白质结构预测模型提供了基于序列的强原子结构先验，实验引导的方法可以利用这些先验来恢复与实验测量一致的结构。然而，在冷冻电镜中，这些先验通常仅在密度重建之后、原子模型拟合阶段才被整合。我们提出了Fold‘EM，一个推理时框架，它将蛋白质生成模型的先验直接与冷冻电镜颗粒图像结合，从少量单颗粒图像中确定原子模型，绕过了中间密度重建和针对重建图的下游模型构建。在合成和实验冷冻电镜数据集上，Fold’EM在已知颗粒取向和从头设定（取向与结构联合推断）下均能恢复准确的原子结构。在异质性数据集中，Fold‘EM还能从混合颗粒群体中解析出不同的构象状态，而无需分别重建密度图并为每个状态构建原子模型。我们相信这些结果为低样本条件下的结构测定以及直接从冷冻电镜颗粒中表征低丰度构象状态开辟了新途径。

### 5. [Discrete Wasserstein Flows for One-Step Generative Modeling](https://arxiv.org/abs/2610.01355v1)
> ⚡ 研究团队提出了一种在有限状态空间上做一步生成建模的新框架，用离散 Wasserstein 几何把 drifting 从连续域扩展到离散 Markov kernel 上。这意味着 LLM 等离散数据场景有望像连续扩散模型一样实现高质量的一步采样，同时训练仍可保留迭代动态，为结构化离散数据生成打下基础。
👤 Alessandro Micheli, Andrea Zerio | 📅 2026-10-01

**详情:** 我们提出了一个用于有限状态空间上单步生成建模的新框架。为了将漂移方法扩展到连续域之外，我们利用离散Wasserstein几何，在可逆马尔可夫核的转移上定义了一个相对于目标的KL梯度流。我们通过马尔可夫跳跃在粒子层面实现了这一概率流，并将由此产生的传输更新摊销到一个以潜变量为条件的生成器中，从而使得迭代动力学仅在训练期间需要，而推理仍然保持单步。在底层分布和传输动力学可以精确计算的可控设置中，我们验证了KL耗散、粒子动力学与概率流之间的一致性，以及预测的数值缩放规律。我们进一步表明，有限容量的神经生成器能够跟踪这些精确的传输目标，同时保持单步生成。这些结果验证了基本构造，并为将离散漂移方法扩展到结构化离散数据提供了基础。

### 1. [KaliBench: A Fine-Grained Benchmark for Cybersecurity Tool Use on Kali Linux with Runtime-Free Verifiable Rewards](https://arxiv.org/abs/2610.02206v1)
> ⚡ KaliBench 团队搞了个专门测 LLM 把自然语言翻译成 Kali Linux CLI 命令的基准，覆盖 1,642 个工具、8,504 条 query-command 对。这事挺关键，因为现有评测根本没抓住真实安全场景里 CLI 语法和参数绑定的坑，而他们发现所有开源模型在无提示下准确率都不到 42%，但用这个数据集做 SFT 和 RL 能让 8B 模型追平 685B MoE。
👤 Pengfei Li, Naufal Suryanto | 📅 2026-10-01

**详情:** 大语言模型正越来越多地应用于网络安全工作流，被期望将分析人员的意图转化为工具调用。然而，现有评估主要集中于基于知识的测评或端到端智能体任务，并未直接衡量大语言模型为真实网络安全工具生成可执行命令的能力。这一空白至关重要，因为网络安全操作依赖严格的命令行界面（CLI），其中微小的语法错误、错误的标志—值绑定或参数顺序错误都可能导致执行失败。我们提出了KaliBench，一个用于Kali Linux上自然语言到CLI翻译的细粒度基准和数据集，包含8，504个查询—命令对，覆盖1，642个工具、23个能力维度和5个安全阶段。KaliBench通过基于手册的流水线构建，采用确定性规范化和别名感知评估，能够对工具选择和参数构造进行精确且可复现的评估。为确保语义正确性和实际可执行性，我们开发了一个多阶段验证流水线，结合了基于大语言模型的验证、沙箱终端执行和人在回路 refinement。基于这些细粒度、确定性的信号，KaliBench进一步支持训练时的无运行时可验证奖励。在三种评估模式和24种通用及安全聚焦开放权重模型配置下，没有任何开放权重模型在无限制设置中超过42%的精确命令准确率，凸显了在没有明确工具提示的情况下准确使用基于CLI的网络安全工具的难度。我们进一步表明，使用KaliBench衍生的可验证奖励进行监督微调和强化学习，可显著提升一个8B模型，并达到与一个685B MoE模型相当的性能。

### 2. [Reconstruct, Practice, Go Real: Guided Self-Improvement for Embodied Agents](https://arxiv.org/abs/2610.02204v1)
