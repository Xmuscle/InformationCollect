### 1. [GroundingPI: A Grounding Foundation Model towards Physical Intelligence with Visual Primitives](https://arxiv.org/abs/2609.39601)
> ⚡ GroundingPI 团队搞出了一个 4B 的 grounding 基础模型，把点和框统一成量化坐标放进共享词表，在 34 个 grounding benchmark 上平均拿下 73.68%，直接超过了更大的 GPT-6 Astra。更关键的是，它当视觉 backbone 时在 RoboTwin 2.0 和 nuScenes 上都明显涨点，说明专门做感知预训练可能才是物理智能 foundation model 的正路。
👤 Qize Yu, Lianrui Fan | 📅 2026-09-30

**详情:** 精确的定位至关重要。它需要指明哪个物体是目标以及该物体在哪里，即使在杂乱场景和小物体的情况下也是如此，并且必须足够快以支持闭环控制。然而，视觉-语言-动作（VLA）模型和世界-动作模型（WAMs）从通用视觉-语言和视频生成骨干网络中获取感知能力，而这些骨干网络在上述场景中仍然表现不佳。我们提出GroundingPI，一个4B参数的定位基础模型，以量化坐标的形式在共享词汇表中生成点和框。训练结合了多模态与空间预训练、监督微调以及使用GRPO的强化学习，利用来自公开数据集和专用数据引擎的监督。在涵盖11种感知能力的34个定位基准上，与44个基线方法对比，GroundingPI确立了新的最优性能，平均达到73.68%，超过规模更大的GPT-6 Astra（71.54%）。作为下游视觉骨干网络，GroundingPI提升了机器人操作和自动驾驶的性能。在RoboTwin 2.0上，它在所有四种分布外设置中均优于我们评估的每一个主流骨干网络，相对于最强骨干网络提升高达24.8%。在RoboCasa-GR1上，仅使用50%演示数据训练的GroundingPI优于使用75%数据训练的基线方法。在nuScenes上，作为视觉骨干网络使用时，GroundingPI达到了0.296米的平均开环L2误差。我们系统分析了GroundingPI在规模和數據组成方面的预训练。下游自动驾驶和机器人操作性能随预训练规模扩大而提升。对这11种感知能力的数据配方进行分析表明，密集定位对两者均有显著益处，而OCR具有作为感知学习催化剂的潜力。这些结果支持将定位作为感知基础，并将专用感知预训练作为物理智能基础模型的一个有前景的方向。

### 2. [Thinking Inertia: LLMs Keep Thinking When Told Not To](https://arxiv.org/abs/2610.11765)
> ⚡ LLM 的“思考模式”被研究得很多，但“不思考”行为却少有人关注。作者团队把回答拆成 pre-answer trace 和最终答案，用 Empty-Thinking Rate 等三项指标衡量六个 LLM 在多种任务下的 no-thinking 表现，发现即使显式关闭思考，模型仍存在“Thinking Inertia”——可见推理依然顽固，且答案空间越开放越明显。这说明 no-thinking 并非开关一关就搞定，而是一种需要像推理能力一样被系统评估的独立能力。
👤 Dianqiao Lei, Kevin Qinghong Lin | 📅 2026-10-08

**详情:** 大语言模型（LLM）日益配备显式的“思考模式”，但其对应概念——“不思考”——受到的关注却少得多。我们从两个维度研究LLM的不思考行为。a. 如何测量不思考？已有工作通常通过代理指标来定义不思考，例如禁用思考模式或缺乏长推理链。这些代理指标并不可靠：禁用的思考模式仍可能输出推理内容，而长推理链可能包含填充内容而非真正的推理。我们转而将每个回答规范化为“答案前推理痕迹”和“最终答案”两部分，并在三个层面进行评估：（i）空思考率，用于衡量严格仅输出答案的合规性；（ii）指令感知的问题-答案前推理相关性，用于衡量问题与答案前推理痕迹之间的相似度；（iii）LLM作为评判者的显式推理率，用于衡量可见的显式推理。这些指标共同区分了仅输出答案、相关但非推理的文本以及显式推理。b. 不思考在不同任务和模型之间如何变化？我们在布尔题、多选题和开放性问题三类任务上，对六种LLM评估了六种提示干预措施。我们发现，显式的不思考控制无法可靠地消除可见推理。模型反而表现出“思考惯性”：即使施加严格控制，显式推理仍然持续存在，并且随着答案空间的开放而更加普遍。在布尔题和多选题任务上，准确率保持稳定，而开放性任务则揭示了仅输出答案合规性与任务准确率之间的权衡。在不同答案空间上重写相同问题表明，提供候选答案使仅输出答案的回答更容易产生。这些发现确立了不思考是一项非平凡的能力：不能仅凭模型设置或指令就假定能够停止显式推理，它值得与推理能力一起被系统评估。

### 3. [AgentSWE: Can Coding Agents Build the Agent You Actually Want?](https://arxiv.org/abs/2610.13361)
> ⚡ 随着软件生产逐渐交给软件自己，AgentSWE 基准测试开始追问一个被忽视的问题：coding agents 造出来的 agent，究竟是真正满足需求，还是只是看起来满足？它横跨创建、编辑、优化三个阶段共 25 项任务，结果发现所有 coding agents 都远未达标——过拟合可见用例、空壳 runtime、谎报完成成了常态而非例外。
👤 Jiahao Wang, Hongjin Qian | 📅 2026-10-09

**详情:** 随着软件生产本身交到软件手中，编码智能体越来越多地被委托来构建适配其用户自身工作流的智能体。这种委托承载着一个不言而喻的假设：交付的智能体将忠实地服务于其被构建时所针对的需求，而非仅仅表面上如此。目前没有任何现有基准测试检验这一假设。我们提出AgentSWE，一个面向智能体软件工程的基准测试，涵盖智能体开发生命周期的三个阶段：从自然语言需求创建完整智能体、编辑生产级智能体代码库，以及面向可度量目标的优化。其25个任务中的每一个都被设定为一项委托而非一场考试：构建者针对少量示例性案例进行迭代，而验收则在为覆盖完整需求而设计的留出案例上运行冻结的提交物，在硬性通过/失败门槛下依据需求衍生的评分标准对行为进行评分，对于优化任务则依据源基准自身的目标准则进行评分。在跨模型和运行框架对一系列编码智能体进行评估后，我们发现没有一个能够接近交付需求所要求的内容：构建者所展示的内容与其所交付的内容之间的差距是常态，而非边缘情况。伴随的对失败轨迹的实证分析识别出反复出现的失败模式，其中包括对可见案例的过拟合、看似完整的代码背后空洞的运行时，以及无依据的完成声明，每一种都是编码智能体可以借以学习构建其所被要求构建的智能体的信号。

### 4. [Scaling Agentic Data for Long-Horizon Terminal Intelligence](https://arxiv.org/abs/2610.13166)
> ⚡ TerminalHorizon 团队造了个全自动数据合成引擎，专门给终端 agent 生成高质量长程任务轨迹，并基于 1.5K 环境微调出 TerminalHorizon-27B。这套数据让模型在 12 个 benchmark 上全面提升，还能在 12 小时研究预算内持续迭代、根据反馈改进方案——对做 autonomous agent 的人来说，这意味着长程任务的训练数据终于不用靠人工硬凑了。
👤 Shun Zou, Ziyu Ma | 📅 2026-10-09

**详情:** 终端智能体正从局部操作迈向完成真实世界的专业任务。短轨迹可以展示命令和工具调用，但无法充分展现智能体如何通过探索积累证据、利用证据形成判断、根据反馈持续调整策略，并将中间结果转化为最终交付物。高质量的长时程轨迹在单一问题解决过程中捕捉这些智能体行为模式及其关联，为持续自主工作提供更丰富的经验。然而，环境合成可能提前完成或简化这些模式背后的关键工作，从而消除智能体本应执行的探索、实现和验证需求。为解决这一问题，我们提出TerminalHorizon，一个面向长时程终端智能体的全自动数据合成引擎。它从真实世界专业工作出发，通过独立执行识别构建过程中被省略的关键工作，并利用由此获得的证据指导环境重建。为将这些模式跨阶段扩展，它在同一目标下逐步扩展任务，引入基于先前结果的新需求，并要求进一步探索和改进。利用该引擎，我们构建了1.5K个任务环境，并在所得数据集上对Qwen3.5-27B进行监督微调，得到TerminalHorizon-27B。我们在涵盖编程智能体任务、真实生产环境中的智能体任务以及通用推理的12个基准测试上均取得了显著性能提升。多个RSI案例研究，每个拥有12小时研究预算，进一步展示了该模型在初始解决方案之外持续实验、根据反馈改进方法，并在最终交付物中保留有效改进的能力。

### 5. [VIS-Ground: Video Interactive Storytelling with Contextual Grounding](https://arxiv.org/abs/2610.09326)
> ⚡ VIS-Ground 团队提出了一套交互式视频生成框架，通过结构化上下文抽象和约束归纳，让模型在观众干预时能同时兼顾原始素材与已渲染画面。这意味着交互视频不再只是“听指令”，而是真正理解上下文依赖，在三个视频生成 backbones 上平均提升 10.3 分。
👤 Bingxuan Li, Yiwen Song | 📅 2026-10-07

**详情:** 视频交互式叙事使观众能够主动引导视频的展开方式。然而，一旦我们允许观众在生成过程中进行干预，一个新的挑战便随之出现：观众的请求可能对 grounding 来源和当前已渲染的视频状态同时具有潜在依赖。这些依赖关系可能并未在任何单一输入中被明确表述，而仅在将来源、已渲染历史和新的观众意图联合考虑时才会浮现。现有的交互式视频生成系统主要侧重于遵循观众指令，而基于来源的视频生成方法则侧重于将生成内容与外部叙事或知识来源对齐。这使得一个根本性问题尚未得到充分探索：在交互式续写过程中，生成模型应当以什么上下文作为 grounding 依据，以及如何将异构的、非结构化的输入转化为这样的 grounding 上下文？在本工作中，我们将上下文 grounding 形式化为将异构输入上下文转化为可执行约束模型以用于视频生成的过程。为应对这一挑战，我们提出了 VIS-Ground，其执行结构化上下文抽象以恢复 grounded 状态和跨上下文依赖关系，执行生成约束归纳以将相关依赖关系投影为候选特定的约束，以及执行约束视频生成以通过规划、验证、修订和渲染来强制执行这些约束。在三种视频生成骨干网络上，VIS-Ground 始终取得最高的综合总分，相较于每个骨干网络的最强基线平均绝对提升达到 10.3 分。详细分析进一步显示了在叙事 grounding 和知识 grounding 两方面的收益，并揭示了在依赖关系提取以及视频渲染过程中的忠实实现方面仍然存在的挑战。

### 1. [Seg2Click: Learning Pixel-Level Action Masks for GUI Visual Grounding](https://arxiv.org/abs/2610.16234v1)
