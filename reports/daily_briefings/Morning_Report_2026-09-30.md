### 1. [Groupwise Agentic Grading and Advantage Redistribution for Code Agent RL](https://arxiv.org/abs/2609.32577)
> ⚡ 小米团队给代码 Agent 的 RL 训练加了个「质检员」GAGAR：不再只看测试是否通过，而是让一个 SFT 训练的 agentic grader 在共享工作区里对通过测试的轨迹按实现质量排名，再据此重新分配 advantage。这样一来，策略能学会偏爱干净、聚焦的改动，而非夹带无关修改的「凑答案」实现，在 310B 到 1T 参数规模的 MiMo-V2.6 上均提升了性能与训练稳定性。
👤 Jinhao Dong, Liang Zhao | 📅 2026-09-26

**详情:** 强化学习（RL）用于代码智能体时，通常使用可执行测试来提供二元奖励。在这些奖励下，组相对策略优化（GRPO）为每个 rollout 组内通过测试的轨迹分配相同的优势值，忽略了实现质量和对任务要求遵循程度上的差异。这使得策略缺乏一种学习信号，无法偏向于干净、有针对性的实现，而非那些包含不必要或超出范围改动的实现。我们提出 GAGAR，一个用于代码智能体强化学习中质量感知信用再分配的框架。GAGAR 基于动态采样构建，保留同时包含通过和失败轨迹的组，并将每组中的所有轨迹置于共享工作区中，由经过 SFT 训练的智能体评分器联合检查它们并对通过测试的候选进行排序。基于该排序，我们降低排名较低轨迹的权重，并按比例重新缩放所有通过测试轨迹的优势值，以恢复其原始总和。这种保持总和不变的再分配保留了基于质量的降权所建立的相对权重，同时将信用转向更高质量的实现。我们使用 MiMo-V2.6-Flash（总参数 310B）和 MiMo-V2.6-Pro（总参数 1.02T）的 RL 前 SFT 检查点，在工业规模上评估 GAGAR。受控的纯代码 Flash 实验显示代码智能体性能提升、轨迹长度增长减少以及训练更加稳定。我们进一步在 Flash 和 Pro 的大规模混合任务 RL 中应用 GAGAR。我们的结果支持将基于测试的验证与组内智能体评分相结合，以提高代码智能体 RL 的质量和稳定性。

### 2. [VisionHOPE: Visual Backbones as Self-Modifying Learning Systems](https://arxiv.org/abs/2609.33325)
> ⚡ 视觉骨干网络又迎来新玩法：团队提出VisionHOPE，首个把视觉backbone做成自修改学习系统，让模型在扫图过程中“记什么”和“怎么学”同步演化。它靠五个耦合记忆和稳定性控制方案，在ImageNet-1K、COCO、ADE20K上打出有竞争力的成绩，意味着自修改学习有望成为通用视觉骨干的实用底座。
👤 Siran Peng, Tianshuo Zhang | 📅 2026-09-27

**详情:** 视觉主干网络已从具有局部聚合能力的卷积神经网络（CNNs）发展到具有全局交互能力的视觉Transformer（ViTs）、具有输入依赖状态转移的状态空间模型（SSMs），以及在处理图像时自适应内部学习器的测试时训练（TTT）层。在这一演进过程中，视觉计算对每个输入的适应性不断增强，然而支配这种适应的规则在很大程度上仍由训练好的主干网络所预设。我们提出VisionHOPE，这是首个被形式化为自修改学习系统的通用视觉主干网络，其中模型所记忆的内容与其学习方式在单张图像内共同演化。基于嵌套学习（NL）的自指构造，VisionHOPE通过五个耦合记忆来实现这种共同演化，这些记忆分别存储内容、生成键和值表示，并调控学习率和保留率。随着视觉上下文沿每次扫描不断累积，这些记忆联合演化。然而，将无约束的自指更新直接应用于视觉主干网络会导致不稳定。因此，我们推导出一种稳定性匹配的步长控制方案，将自指注入的软上限与保留记忆转移的谱钳制相结合，并证明了由此产生的记忆动力学沿每次扫描是非扩张的。对于二维特征图，我们通过将块与图像的行和列在四个方向扫描中对齐，来适配NL的块公式。所提出的VisionHOPE在ImageNet-1K、COCO和ADE20K上取得了具有竞争力的结果，确立了自修改学习系统作为通用视觉主干网络实用基础的地位。代码可在https://github.com/PSRben/VisionHOPE获取。

### 3. [Recursive Harness Distillation across Agents for Robot Manipulation](https://arxiv.org/abs/2609.33378)
> ⚡ 研究团队提出 Recursive Harness Distillation，让强 agent 把失败诊断与干预经验蒸馏成 playbook，再用轻量 agent 的执行反馈递归优化，无需更新模型参数即可复用。真实机器人操作成功率从 37.3% 提升至 64.0%，SimplerEnv Bridge 上轻量 agent 达 66.7%，远超 GR00T-only 的 41.7%，说明 VLA 模型的干预经验可以跨 agent 积累和迁移。
👤 Seungyeon Kim, Junhoo Lee | 📅 2026-09-27

**详情:** 机器人学的一个核心目标是实现跨变化任务和环境的操作。视觉-语言-动作（VLA）模型提供了广泛的操作能力，但当执行需要诊断失败并调整行为时，它们可能表现不佳。强智能体可以通过与这些策略的交互发现有效的干预措施。我们提出递归框架蒸馏（Recursive Harness Distillation），将这种经验积累为可跨智能体复用的指导。强智能体将其经验蒸馏为轻量智能体的操作手册，然后利用轻量智能体的执行反馈递归地改进该手册。所得的操作手册使智能体能够在新的任务实例中复用积累的干预知识，而无需更新模型参数。在真实世界操作中，该框架将成功率从37.3%提升至64.0%。在SimplerEnv Bridge上，配备操作手册的轻量智能体达到了66.7%的成功率，而仅使用GR00T的基线为41.7%，并且优于没有操作手册的强智能体。同一操作手册也惠及强智能体，使其成功率达到79.2%。这些结果证明了框架蒸馏在机器人学中的可行性：干预经验可以被积累、通过执行加以改进，并跨智能体复用以提升操作能力。

### 4. [SentZero: An Enhanced Sentence-Centric Vision-Language Pretraining for Multi-Task Zero-Shot Chest X-Ray Analysis](https://arxiv.org/abs/2609.34479)
> ⚡ 研究团队提出SentZero，一个以句子为核心的视觉-语言预训练框架，利用LLM做抽象级句子结构化与映射来扩充正样本对，并加入额外损失项以缓解假阴性问题。这意味着CXR分析有望摆脱任务特定finetuning，在零样本多任务场景下实现更强的泛化能力。
👤 Hangyul Yoon, Hyungyung Lee | 📅 2026-09-28

**详情:** 使用配对的胸部X射线（CXR）图像和放射学报告进行视觉-语言（VL）预训练，已展现出在医学图像理解方面的强大潜力。然而，现有方法往往仍依赖于任务特定的微调，因为放射学报告篇幅冗长、临床信息密集，且难以与简单的零样本提示对齐。近期基于句子级别的方法通过大语言模型（LLM）提取的临床短语部分缓解了这一局限，但它们在很大程度上忽视了放射学话语的内在特征。具体而言，有限的正样本对多样性制约了进一步提升，而临床等价的句子在不同患者间频繁重复出现，在对比学习中造成假阴性。为解决这些问题，我们提出SentZero，一种增强的以句子为中心的VL预训练框架，用于零样本、多任务CXR分析。SentZero引入基于LLM的抽象级句子结构化和映射以扩展正样本对多样性，并增加一个额外的损失项以缓解假阴性问题。我们进一步引入句子条件化的视觉嵌入残差调制，使视觉特征能够适应每个输入句子的语义特征。在多样化的下游任务和数据集上，SentZero提升了零样本泛化能力，并优于先前的多任务零样本方法。

### 5. [FlowTool: Controlling Tool Parameter in Image Retouching via Flow Matching](https://arxiv.org/abs/2609.35673)
> ⚡ FlowTool团队把工具式图像编辑从自回归推理改成了条件生成问题，用rectified flow直接建模高质量工具参数的分布，让Diffusion Transformer从噪声中生成编辑方案。这意味着不再依赖MLLM逐步推理，在多个benchmark上反超专用编辑agent和闭源MLLM，推理延迟至少降低50倍、内存省近2倍——工具式编辑或许根本不需要自回归那套。
👤 Thanh-Long V. Le, Steven Walton | 📅 2026-09-28

**详情:** 基于工具的图像编辑（图像修饰）通常采用自回归多模态大语言模型（MLLMs）来实现，依次生成推理过程、工具选择和参数值。在本工作中，我们提出了一种新颖的基于工具的图像编辑方法，将该任务构建为流匹配问题。我们引入了FlowTool，一个利用条件修正流直接建模以输入图像和用户指令为条件的高质量工具参数分布的框架。FlowTool将用于多模态理解的视觉-语言模型骨干网络与一个扩散Transformer参数生成器相结合，后者将高斯噪声转换为编辑方案。我们采用两阶段监督流匹配课程训练FlowTool，随后进行基于奖励的后训练。在MMArt-Bench、FlowTool-Eval、ArtEdit-Bench和MIT-Adobe5K上，FlowTool在有参考评估下取得了显著优于专用MLLM编辑代理和专有MLLM的性能，同时在无参考评估下与专有模型保持竞争力。此外，FlowTool显著提升了推理效率，相比对比基线至少降低50倍的延迟，同时所需内存减少近2倍。这些结果表明，基于工具的图像编辑可以有效地建模为结构化连续编辑参数上的条件生成，而无需自回归推理。

### 1. [Skill-Space Shooting for Autonomous Robot Policy Improvement](https://arxiv.org/abs/2609.38178v1)
> ⚡ 机器人要在真实世界里越干越聪明，关键得靠自己从失败中学习，而不是每次出错都等人来示范纠正。新提出的 skill-space shooting 用 foundation model 引导机器人通过可复用的 skills 探索修正动作，再把成功经验反哺成 policy improvement——这意味着机器人能自主持续进步，而且 skills 还能跨任务共享，大幅减少教新任务的成本。
👤 Zihang Rui, Renhao Wang | 📅 2026-09-29

**详情:** 部署在物理世界中的机器人必须能够在遇到新情况和失败时超越其初始训练而持续改进。为了使这种改进能够跨任务扩展，它必须有效利用经验，而不需要人类对每次纠正进行演示。近期的智能体系统提供了一种减少对人类努力依赖的方法，即利用基础模型自主组合已学习的行为来完成任务。然而，以这种方式完成任务本身并不能教会任务策略克服自身的失败；这需要将这些行为转化为策略可学习的纠正。我们的洞察是，许多此类纠正是熟悉的短行为，即技能：它们在不同任务中反复出现，并描述了基础模型能够从场景中推理出的动作。我们提出了技能空间射击（skill-space shooting），它利用基础模型引导通过这些可复用技能来探索纠正，并将成功的试验转化为策略改进。真实世界实验表明，自主行动的策略能够持续改进，同时技能也可以被共享，以减少改进新任务所需的教导。通过使可复用技能成为纠正性监督的来源，技能空间射击实现了任务内和跨任务的可扩展且可泛化的策略改进。更多结果和视频见 https://skill-space-shooting.github.io。

### 2. [Thinking Before Thinking: Scaling Agentic Inference Through Meta-Reasoning](https://arxiv.org/abs/2609.38147v1)
> ⚡ 研究团队提出了一种叫 agentic meta-reasoning 的推理时控制框架，让 worker 专注执行任务，controller 则负责整合进展、评估选项并在预算内调度下一步，同时只保留精简的运行摘要而非完整历史。在 ProgramBench 上，它让 GPT-5.5 拿到 71.5%、远超 Codex 的 58.0%，在多个长程推理基准上也稳定领先直接控制 3.6 到 4.2 分。这说明 agent 跑得越久，把算力花在结构化控制上就越关键。
👤 Paras Dahal, Anton Bakhtin | 📅 2026-09-29
