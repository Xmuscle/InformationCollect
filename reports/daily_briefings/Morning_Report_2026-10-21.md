### 1. [MemT-1.0: Towards Memory-Native Evolution](https://arxiv.org/abs/2610.26825)
> ⚡ 研究团队推出 MemT-1.0，把记忆直接内化为模型计算的一部分——基于 Metis 架构，用 Gated DeltaNet-2 做 token 级记忆更新，还引入 Mixture-of-Storage 扩展记忆容量，并开源了 Nano 和 Flash 两个版本。这意味着记忆不再是外挂模块，128K 上下文下 Nano 端到端推理提速约 1.86 倍、持久存储比全量 KV cache 省 66 倍，agentic 任务成功率也涨了，算是朝 memory-native 演进迈出的实用一步。
👤 Zhiyu Li, Zeyu Zhang | 📅 2026-10-19

**详情:** 记忆原生进化要求将记忆作为基础模型的内在能力，使其能够持续积累和利用信息。为此，我们提出MemT-1.0，一种将记忆内化为模型计算组成部分的记忆基础模型新架构。MemT-1.0基于Metis构建，在每个回合内采用具有稳定token级记忆更新机制的Gated DeltaNet-2。我们进一步引入混合存储（Mixture-of-Storage）以扩展原生记忆容量。经过审慎的主干准备，我们开发了由持续预训练和后训练组成的两阶段训练流程，并辅以34B token的训练数据以及高效的训练和推理基础设施。我们发布了包含MemT-1.0-Nano和MemT-1.0-Flash的模型系列，并对记忆能力和通用能力进行了全面评估。结果表明，它们在平均表现上优于参数化记忆基线，与检索增强方法相比仍具竞争力，同时基本保持了通用能力。在128K token的历史长度下，MemT-1.0-Nano相较于全上下文KV缓存实现了约1.86倍的端到端推理加速和66倍的持久存储缩减。通过内化检索到的程序性经验，MemT-1.0提升了智能体任务的任务成功率，为记忆原生进化迈出了切实的一步。

### 2. [SpecMRL: Redesign Matryoshka Representation Learning within Parametric Spectrum](https://arxiv.org/abs/2610.26824)
> ⚡ 研究团队提出SpecMRL，在Matryoshka Representation Learning基础上引入按特征重要性排序的spectral basis，让prefix readout在学习到的谱空间中进行。MTEB实验显示它在所有压缩维度上都优于MRL，压缩越狠优势越明显，甚至用一半embedding维度就超过了全维度MRL——说明这个谱基确实能更好地把信息压进前缀里。
👤 Zhongxin Chen, Songhao Wu | 📅 2026-10-19

**详情:** Matryoshka表示学习（MRL）通过联合优化嵌套前缀来支持灵活的表征尺寸。尽管该方法有效，但其设计缺乏显式约束以确保前导部分提供合适的紧凑编码。为解决这一问题，我们提出了SpecMRL，通过重新组织特征空间来实现更有效的前缀读取。具体而言，我们用一个由参数导出、按特征重要性组织的谱基来扩展MRL。SpecMRL在其他方面遵循标准MRL，前缀读取在学习到的谱空间中执行。在MTEB上的实验表明，SpecMRL在所有评估的降维维度上均优于MRL，且在更激进的压缩下增益更大。这些结果表明，学习到的谱基更好地优先考虑了信息量大的方向，从而实现了更有效的表征压缩。值得注意的是，SpecMRL拓展了MRL的性能前沿，仅用一半的嵌入维度便超越了全维度的MRL。

### 3. [Kronecker Delta Rule for Long Context Linear Attention](https://arxiv.org/abs/2610.26834)
> ⚡ NX-AI 团队提出 KronLSTM，一种基于 Kronecker Delta Rule 的线性注意力架构，通过单方向矩阵修正实现微创式记忆修订，减少对已存信息的干扰。它在长上下文建模中表现亮眼，稳定性和性能常优于 DeltaNet 系列，且无需额外归一化机制，代码和模型均已开源。
👤 Anamaria-Roberta Hartl, Levente Zólyomi | 📅 2026-10-19

**详情:** 我们提出了KronLSTM，一种基于Kronecker Delta规则的线性注意力架构，该规则是一种用于关联矩阵记忆的新型更新规则。KronLSTM扩展了xLSTM系列，引入了一种记忆修正机制，该机制能够修正目标关联，同时仅沿矩阵空间中的单一方向修改记忆。与delta规则更新相比，这种微创式记忆修正减少了对已存储信息的干扰，使其特别适用于长上下文语言建模。由此产生的记忆动力学可以在数学上描述为一个收敛到稳态分布的马尔可夫链，同时记忆矩阵的期望范数在整个输入序列中始终保持一致有界。因此，KronLSTM确保了稳定的记忆动力学，而无需对记忆状态施加额外的归一化和稳定化机制。实验表明，KronLSTM与现有的线性注意力架构（包括(Gated) DeltaNet系列模型）相比具有竞争力，且往往表现更优，在长上下文基准测试中表现尤为突出。这些结果确立了Kronecker Delta规则作为循环线性注意力架构中稳定关联记忆的有效且可解析分析的基础。我们的代码（https://github.com/NX-AI/KronLSTM）和模型（https://huggingface.co/collections/NX-AI/kronlstm）均已开源。

### 4. [AdaExploreBench: Benchmarking LLM Agents for Proactive Exploration and Test-time Adaptation in Evolving Environments](https://arxiv.org/abs/2610.25950)
> ⚡ LLM agent 在陌生且动态变化的环境里往往缺乏主动探索能力，研究团队为此推出 AdaExploreBench，用隐藏规则和隐式规则漂移来测试 agent 能否主动取证、推断规则并在性能下降时重新探索。测试显示包括 GPT-6 Sol 在内的八款领先 LLM 表现都不理想，最佳校准准确率仅 61.9%，说明当前 agent 的瓶颈不在推理，而在于主动获取正确证据、并及时察觉旧知识已失效。
👤 Rui Wang, Zishen Lai | 📅 2026-10-19

**详情:** 大语言模型（LLM）智能体正日益被部署于陌生且不断演变的环境中，这要求它们主动探索、理解并适应环境动态。然而，现有基准测试很少检验智能体能否主动发现环境的运作方式并随环境演变而适应。为填补这一空白，我们提出AdaExploreBench，一个用于演变环境中主动探索与测试时适应的基准测试。通过将环境动态实例化为隐藏规则，AdaExploreBench要求智能体主动获取证据并推断规则。在隐式规则漂移下，潜在规则在无公告的情况下发生变化，要求智能体从性能下降中检测到先验知识已过时并重新探索。在八个领先LLM上的实验表明，主动且自适应的探索仍然具有挑战性：GPT-6 Sol仅达到61.9%的校准准确率，而提供充分证据或消除规则漂移可使平均性能显著提升近10%。这些结果揭示了当前LLM智能体的一个关键瓶颈：一旦信息性证据可用，它们通常能够有效地进行推理，但难以主动获取正确的证据，并难以识别先前获取的证据何时不再有效。

### 5. [MemPilot: Orchestrating On-Demand Multimodal Memory Curation for LLM Agents](https://arxiv.org/abs/2610.06830)
> ⚡ MemPilot 团队提出了一套灵活的 agent memory 框架，通过强化学习训练多步 LLM policy，让模型在运行时自主决定何时检索 query-agnostic memory、何时把原始多模态历史交给异构 LLM 和 VLM 做按需整理。这意味着 agent 能在性能、成本和延迟之间做细粒度权衡，而不是被固定的记忆处理流程绑死，在五个多模态基准上都跑出了更优的 trade-off 前沿。
👤 Haozhen Zhang, Haodong Yue | 📅 2026-10-05

**详情:** 记忆已成为LLM智能体生态系统中不可或缺的组成部分，支撑跨交互的信息保留与复用。然而，现有大多数智能体记忆系统以与查询无关的方式构建记忆，这可能导致不必要的预处理开销，并丢弃后续被证明至关重要的细节。近期研究已开始将记忆处理转向运行时自适应，但通常局限于特定操作或固定处理方案，对性能、成本和延迟的灵活控制在很大程度上仍未得到充分探索。为应对这一挑战，我们提出MemPilot，一个灵活的框架，能够在不同的性能—成本—延迟偏好下按需编排记忆管理。具体而言，我们通过强化学习优化一个多步LLM策略，使其迭代地在从查询无关记忆中检索与将原始多模态历史的查询特定管理委托给异构LLM和VLM之间进行选择。该策略联合控制证据量、管理指令、模型选择和视觉访问，从而实现运行时计算的细粒度分配。为在竞争性目标下优化该策略，我们采用目标级优势解耦方法，在聚合之前分别估计每个目标的优势。此外，我们引入基于前缀的边际效用估计，用于多步 rollout 中的细粒度信用分配。在五个多模态智能体记忆基准上的实验表明，该框架在不同优化偏好下均展现出良好的性能—成本—延迟权衡，且偏好扫描所产生的前沿面优于现有的权衡感知基线。

### 1. [SolarRenderer: Few-Step Generative Reference Rendering](https://arxiv.org/abs/2610.28630v1)
> ⚡ MiniMax团队提出SolarRenderer，用两个轻量LoRA适配冻结的33B MiniMax-H3骨干，把任意结构视频接入原生参考通路，实现四步渲染、比50步采样快12.3倍，并有实时768p的流式版本。这意味着游戏引擎和coding agents给出的粗粒度场景结构，终于能低成本、跨表示地转成逼真视频，还泛化到姿态骨架、手绘和点云等11种未见表示。
👤 Guian Fang, Shengju Qian | 📅 2026-10-20

**详情:** 游戏引擎和编码智能体能够指定场景的布局、运动和相机，但要将这种粗粒度结构转化为逼真的视频，需要一个能够遵循该结构并补全其未指定外观的渲染器。现有渲染器受限于单一引擎的表示方式，需要数十步去噪或昂贵的自蒸馏，并且从与其目标视频不对齐的条件中学习。我们提出SolarRenderer，一种结构条件视频渲染器，它通过两个轻量级LoRA适配冻结的MiniMax-H3 33B骨干网络。结构视频在其所描述帧的位置进入骨干网络的原生参考通路，无需类型标识符，仅以纯文本描述，从而使单个控制LoRA能够遵循任意结构表示。从预训练的四步LoRA出发，结构引导的分布匹配在四步内完成渲染，比50步采样快12.3倍，同时保持所学控制。块因果变体将相同设计扩展到流式场景，实时渲染768p视频。为训练模型，我们构建了一个帧对齐语料库，包含来自游戏引擎、模拟器和YouTube视频的136K个片段。在分布内测试集和涵盖16种结构表示的泛化基准上的实验表明，SolarRenderer在两者上均达到最先进结果，并泛化到11种未见过的表示，包括姿态骨架、绘画和点云。

### 2. [GBClaw: An agentic AI framework for atomistic grain boundary research and mechanistic discovery](https://arxiv.org/abs/2610.28629v1)
