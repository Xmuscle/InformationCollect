### 1. [EnvHarness: Awakening Static Worlds for Agent Learning](https://arxiv.org/abs/2608.19880)
> ⚡ EnvHarness团队提出了一个可编程的环境层，通过插件组件在不改动底层逻辑的情况下重塑静态环境，并配套EnvRigger自动诊断策略缺陷并生成针对性组件。这项工作的意义在于，它让LLM agent的训练环境从一次性消耗品变成了可动态演化的工具，在四个领域的五个基准上比原始环境平均提升9.0分，还能减少近10%的执行步骤，为强化学习提供了更高效的优化信号。
👤 Chengsong Huang, Zifeng Wang | 📅 2026-08-20

**详情:** LLM智能体通过与环境的互动进行学习，然而这些环境均为手工构建且静态不变：它们对智能体的弱点视而不见，并随着智能体的进步迅速失去挑战性。尽管近期环境生成方法试图解决这一问题，但它们依赖于特定领域的流水线，依赖昂贵或不可靠的验证器，且仍生成静态环境。为减轻从零重建环境的工程负担，我们提出环境操控框架（EnvHarness），这是一个可编程的即插即用组件层，通过包裹静态环境来重塑其行为，而无需修改底层逻辑。EnvHarness通过标准接口运作，适用于多种领域，同时确保每个重塑后的环境保留其原始验证器。为使该过程自动化，我们引入EnvRigger，它将目标策略视为黑盒，通过观察其执行轨迹来合成针对已诊断缺陷的EnvHarness组件，并通过全新回滚进行验证。在四个领域的五个基准测试中，EnvHarness在保留实例上优于原始环境和特定领域的环境生成流水线，最高提升达9.0分，同时执行步骤减少9.8%。此外，EnvHarness为强化学习提供了更优的优化信号，使策略与其环境能够持续、有针对性地协同进化。

### 2. [SemComp-Bench: Benchmarking Semantic Task Completion in Video Generation](https://arxiv.org/abs/2608.17426)
> ⚡ 我们提出了一项面向结果导向的视频生成任务——Semantic Task Completion Video Generation，要求生成视频既要达成任务目标，又要与参考图像保持任务相关的高层语义一致性（semantic grounding）。为此我们构建了覆盖六领域的评估数据集SemComp-Data，并设计了基于VLM的SemComp-Bench协议，分别用OA Score和GR Score衡量结果达成度与生成可靠性。实验显示，现有主流视频生成模型在这项任务上仍力不从心，这为后续研究指明了方向。
👤 Keyu Tu, Zhuowei Chen | 📅 2026-08-18

**详情:** 我们提出语义任务完成视频生成，这是一种面向结果的视频生成任务。在此框架下，成功既要求达成预期结果，也要求实现语义基础对齐。语义基础对齐刻画了参考图像与生成结果之间在任务相关高层语义上的对应关系。评估聚焦于生成结果，既不要求呈现完整的中间任务步骤序列，也不要求与参考图像保持传统的外观一致性。为支持系统性评估，我们构建了SemComp-Data，一个覆盖六个领域的评估数据集。每个实例包含一张参考图像、一条详细指令、一条简要指令以及一段以结果为中心的视频片段。一个可扩展的四阶段整理流程将原始视频转化为标准化的SemComp-Data实例。我们进一步引入SemComp-Bench，一种评估协议，利用视觉语言模型（VLM）回答结构化的是非问题。SemComp-Bench分别报告用于衡量结果达成和生成可靠性的OA分数与GR分数。在代表性视频生成模型上的实验表明，在达成预期结果的同时保持参考图像中任务相关语义基础对齐仍然具有挑战性。

**详情:** 具身智能体越来越多地被用于弥合端到端策略模型所遗留的差距。然而，智能体路径尚未在物理执行中实现闭环学习：现有的框架在很大程度上仍是开环的，在展开过程中遵循固定技能，并且仅在一轮情节结束后才进行反思。这种事后反思无法在执行过程中实时指导行为，因为物理交互要求决策以超出当今大型智能体模型能力的频率来跟踪快速变化的机器人-环境状态。我们提出了Zetta，一种闭环具身框架，它在保持基础策略冻结的同时，在线演化基于代码的运行时批评者和恢复技能。通过三个时间尺度分离的循环，Zetta提供了动作频率治理、展开级批评-恢复提议以及验证门控的技能更新。结合Z-Infra（一种将智能体逻辑与异构执行资源解耦的展开基础设施），Zetta在我们当前的展开预算下在LIBERO-Pro和RoboCasa上达到了最先进的成功率，分别达到90.8%和93.6%，并实现了11.1倍的推理加速；其成功率随着自我探索经验的积累而持续提升；所学技能可零样本迁移，并出现了清晰的机器人“顿悟时刻”。这些结果表明，闭环框架的自我演化开辟了一条通往可靠物理智能的扩展路径。

### 4. [SemaPLC: A Project-Grounded, Verification-Gated Agent Harness for PLC Code Generation](https://arxiv.org/abs/2608.18565)
> ⚡ SemaPLC 团队推出了一款基于验证门控的 agent 框架，用外部日志检查替代模型自评，确保生成的 PLC 控制逻辑在编译、规范和真实 runtime 上全部通过后才算完成。在 117 个独立 POU 任务和 65 个项目上下文任务中，它均取得最高严格通过率，尤其在动态行为测试中（52.2 分 vs 基线最高 31.4）拉开明显差距。这提醒我们，静态评分远不如实际执行能反映控制逻辑的真实可靠性，而 SemaPLC 已开源，值得一试。
👤 Yanlun Tu, Huacan Wang | 📅 2026-08-19

**详情:** 可编程逻辑控制器（PLC）驱动着工业工厂的运行，而大型语言模型已能够为其生成独立的程序组织单元（POU）。然而，此类逻辑能否集成到现有PLC项目中并正确运行，目前仅在有限的测试中得到验证。我们提出了SemaPLC，一个基于项目环境且以验证为门槛的智能体框架，它由常规工具组装而成，但受严格的完成规则约束。SemaPLC并非在模型自行判断输出足够时停止，而是仅在记录在案的外部检查确认通过后才宣布任务完成。这些检查涵盖规格说明、编译以及在实际运行时的行为表现。在匹配现有基准的117个独立POU任务中，SemaPLC在所有七个模型上取得了最高的严格验证通过率（平均72.6%）。在包含65个任务的项目上下文轨道中，生成的逻辑必须在真实项目内编译并运行，SemaPLC在集成编译、静态行为和动态行为方面均取得了最高平均值。在这三个层次中，动态行为最具揭示性。我们通过将生成的逻辑与参考逻辑部署到实际PLC运行时并比较其执行轨迹来对其进行衡量。所有方法在静态得分上彼此相差在10个百分点以内，而动态得分则将其显著区分开来，基线方法的得分从22.4到31.4不等，而SemaPLC则达到52.2。总体而言，我们的验证门槛框架在每个层次上都提高了平均值，且在运行时层面提升最为显著。执行，而非静态评分，才是检验生成的控制逻辑是否真正有效的可靠标准。SemaPLC已在https://github.com/midea-ai/SemaPLC开源。

### 5. [FACET: Preserving Source Intent and Executable State in Terminal Task Synthesis](https://arxiv.org/abs/2608.18580)
> ⚡ FACET框架通过细粒度智能体构建，将相关终端技能重构为信息丰富的场景，并修复执行环境以生成可执行任务，确保指令、解决方案和验证器共享同一容器状态。这一方法解决了多阶段合成中信息丢失和跨组件不一致的痛点，其生成的密集可执行检查使微调后的模型在Terminal-Bench 2.1上持续提升性能，为可扩展终端任务合成确立了环境接地与意图保留两大关键原则。
👤 Kou Shi, Zun Wang | 📅 2026-08-19

**详情:** 训练终端代理需要可扩展的可执行监督，然而合成高质量的终端任务仍具挑战性。每个任务都耦合了指令、初始化环境、参考解决方案和可执行验证器；如果这些构件由不一致的假设生成，所得到的任务可能无法求解或被错误评估。与此同时，多阶段合成可能会丢弃原始来源中编码的目标、依赖关系、状态转换和过程约束。我们提出FACET（可执行任务的细粒度智能体化构建），一个同时解决信息保留和跨构件一致性的框架。FACET将相关的智能体技能重构为连贯、信息丰富的场景，然后在生成最终任务构件之前实现并修复执行环境。所得到的容器状态作为指令、解决方案和验证器的共享基础，而基于执行的验证和针对性修复则纠正特定构件的失败，无需不必要地重新生成有效组件。FACET生成具有密集可执行检查的复杂终端任务，从这些任务中收集的成功轨迹提供了有效且数据高效的监督。在多个规模上对模型进行微调持续提升了Terminal-Bench 2.1上的性能，而对替代生成方案的分析则支持了环境基础构建对任务有效性和解决方案-验证器一致性的重要性。这些结果确立了源意图保留和共享可执行状态基础作为可扩展终端任务合成的关键原则。
